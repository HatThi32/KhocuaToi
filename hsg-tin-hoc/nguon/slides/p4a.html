Vì sao dùng hàm?

Chương trình con

Hàm là đoạn lệnh có tên, làm một việc cụ thể, gọi lại nhiều lần.

Lợi ích: tránh lặp mã; chia nhỏ bài toán lớn; dễ kiểm thử, dễ sửa; nhiều người cùng làm.

Hàm có sẵn: len, max, print… Hàm do ta viết: dùng def.

def chao(ten):
    print("Xin chao", ten)

chao("An")
chao("Binh")
Kết quả
Xin chao An
Xin chao Binh
def chỉ định nghĩa hàm, chưa chạy. Hàm chỉ chạy khi được gọi.

Cú pháp hàm và lời gọi

Các thành phần

  • def tên(tham_số): — dòng đầu, có dấu :.
  • Thân hàm thụt lề.
  • return giá_trị — trả kết quả và kết thúc hàm.
  • Gọi: tên(đối_số).
  • Tham số: tên trong định nghĩa; đối số: giá trị truyền khi gọi.
def binh_phuong(x):
    return x * x

print(binh_phuong(5))
print(binh_phuong(3) + binh_phuong(4))
kq = binh_phuong(2) ** 2
print(kq)

Trả về nhiều giá trị; return sớm

Tuple và thoát sớm

return a, b thực chất trả về một tuple; nhận bằng x, y = f().

return kết thúc hàm ngay, nên dùng để thoát sớm khi đã biết kết quả.

def min_max(a):
    return min(a), max(a)

lo, hi = min_max([4, 9, 2])
print(lo, hi, min_max([4, 9, 2]))

def co_chan(a):
    for x in a:
        if x % 2 == 0:
            return True
    return False
print(co_chan([1, 3, 4, 5]), co_chan([1, 3]))

Tham số: vị trí, tên, mặc định

Ba cách truyền

Theo vị trí: f(2, 3).

Theo tên: f(b=3, a=2) — thứ tự tuỳ ý.

Giá trị mặc định: def f(a, b=10); tham số có mặc định phải đứng sau tham số không mặc định.

*args nhận số lượng tuỳ ý đối số (thành tuple).

def luy_thua(a, n=2):
    return a ** n

print(luy_thua(5))
print(luy_thua(2, 10))
print(luy_thua(n=3, a=2))

def tong(*args):
    return sum(args)
print(tong(1, 2, 3, 4))

Truyền vào hàm: biến bên ngoài có bị đổi không?

Số và xâu (bất biến)

Truyền số, xâu, tuple (bất biến): đổi trong hàm không ảnh hưởng biến bên ngoài.

Truyền list, dict, set (khả biến) và sửa tại chỗ: biến bên ngoài bị đổi.

def f(x):

ds = [1]

Bẫy: tham số mặc định là danh sách

Mặc định chỉ tạo MỘT LẦN

Giá trị mặc định được tạo một lần khi định nghĩa hàm; nếu là list thì mọi lần gọi dùng chung list đó.

Cách đúng: mặc định None, tạo list mới trong hàm.

def them(x, ds=[]):
    ds.append(x)
    return ds

a = them(1)
b = them(2)
c = them(3, [])
print(a, b, c, a is b)

def dung(x, ds=None):
    if ds is None:
        ds = []
    ds.append(x)
    return ds
print(dung(1), dung(2))
Kết quả
[1, 2] [1, 2] [3] True
[1] [2]
a và b là cùng một danh sách [1, 2]; c dùng danh sách riêng [3].

Hàm gọi hàm, hàm trả về hàm

Tổ hợp hàm

Hàm có thể gọi hàm khác: chia nhỏ bài toán.

Hàm cũng là giá trị: truyền làm đối số, hoặc trả về.

def nt(n):
    return n > 1 and all(n % d for d in range(2, int(n ** 0.5) + 1))

def dem_nt(a, b):
    return sum(1 for i in range(a, b + 1) if nt(i))

print(dem_nt(1, 50))

def ap_dung(f, ds):
    return [f(x) for x in ds]
print(ap_dung(abs, [-3, 4, -5]))

[3, 4, 5]

Hàm lambda

Hàm ẩn danh một dòng

lambda tham_số: biểu_thức — trả về giá trị biểu thức.

Hay dùng làm key khi sắp xếp, hoặc với map, filter.

Chỉ chứa một biểu thức, không có lệnh.

b = lambda x: x * x
print(b(7))
t = ["lan", "an", "binh"]
print(sorted(t, key=lambda w: len(w)))
print(list(map(lambda x: x + 1, [1, 2, 3])))
print(list(filter(lambda x: x % 2, range(8))))

Biến cục bộ và biến toàn cục

Quy tắc LEGB đơn giản

Cục bộ: biến tạo ra trong hàm, chỉ tồn tại khi hàm chạy.

Toàn cục: biến tạo ở ngoài mọi hàm, hàm đọc được.

Trong hàm, gán cho một tên là tạo biến cục bộ mới (che biến toàn cục cùng tên).

x = 7
def g():

    return x * 2

y = g()
print(x, y, doc())

Lỗi UnboundLocalError

Vừa đọc vừa gán trong hàm

Nếu trong hàm có phép gán cho một tên thì tên đó là cục bộ trong cả hàm, kể cả ở những dòng trước phép gán.

Đọc nó trước khi gán → UnboundLocalError.

Muốn sửa biến toàn cục: khai báo global.

dem = 0
def tang():
    dem += 1

tang()
Kết quả
UnboundLocalError: cannot access local variable 'dem' where it is not associated with a value
dem = 0
def tang():
    global dem
    dem += 1

tang()
tang()
print(dem)

global và nonlocal

Khai báo phạm vi

global x: trong hàm, x là biến toàn cục (cho phép gán).

nonlocal x: trong hàm lồng, x là biến của hàm bao ngoài (không phải toàn cục).

Chỉ cần khai báo khi gán; chỉ đọc thì không cần.

x = 10
def f():
    x = 20
    def g():
        nonlocal x
        x += 1
        return x
    return g()
def h():
    global x
    x += 5
    return x
print(f(), x, h(), x)
Kết quả
21 10 15 15
Thứ tự tính: f() = 21 (x toàn cục vẫn 10); h() đổi x thành 15 nên 4 giá trị: 21, 10, 15, 15.

Nên tránh biến toàn cục

Nguyên tắc lập trình tốt

Hàm tốt chỉ phụ thuộc vào tham số và cho kết quả qua return (hàm “thuần”).

Dùng biến toàn cục làm hàm khó kiểm thử, dễ lỗi khi nhiều hàm cùng sửa.

Ngoại lệ hợp lí: hằng số (viết hoa: MAX = 100).

# xấu
tong = 0
def cong(a):
    global tong
    tong += a

# tốt
def cong2(tong, a):
    return tong + a

t = 0
for v in [3, 4, 5]:
    t = cong2(t, v)
print(t)

Thiết kế chương trình bằng hàm

Chia để trị

  1. Xác định đầu vào, đầu ra của bài.
  2. Tách thành các việc nhỏ, mỗi việc một hàm.
  3. Đặt tên hàm rõ nghĩa (động từ), viết chú thích ngắn.
  4. Kiểm thử từng hàm trước khi ghép lại.
def doc_day():
    return list(map(int, input().split()))

def tb(a):
    return sum(a) / len(a)

def dem_tren_tb(a):
    m = tb(a)
    return sum(1 for x in a if x > m)

a = doc_day()
print(f"{tb(a):.2f}", dem_tren_tb(a))

Docstring và kiểu gợi ý

Tài liệu hoá hàm

Docstring: xâu ba nháy ngay dưới dòng def, mô tả hàm; xem bằng help(f).

Gợi ý kiểu (type hint): def f(a: int) -> int: — chỉ để đọc hiểu, Python không bắt buộc.

Đặt tên tham số rõ nghĩa tốt hơn chú thích dài.

def uoc_chung(a: int, b: int) -> int:
    """Tra ve UCLN cua a va b (Euclid)."""
    while b:
        a, b = b, a % b
    return a

print(uoc_chung(48, 18))
print(uoc_chung.__doc__)
Kết quả
6
Tra ve UCLN cua a va b (Euclid).

h(): dùng global, x toàn cục = 7 + 1 = 8.

Tự kiểm tra (HSG): hàm sinh bình phương

Câu hỏi

Chương trình in ra gì? (Chú ý f(0).)

def f(n):
    kq = []
    for i in range(n):
        kq.append(i * i)
    return kq
print(f(4), len(f(0)))

Đáp án và giải thích từng bước

f(4): i = 0, 1, 2, 3 → [0, 1, 4, 9].

f(0): range(0) rỗng → trả về [] (không phải None) → len = 0.

Tự kiểm tra (HSG): return đặt sai chỗ

Câu hỏi

Hàm sau định kiểm tra “mọi phần tử đều dương”. Cho kết quả với [3, -1, 5] và [4, 6]. Sửa lỗi.

def all_pos(a):
    for x in a:
        if x > 0:
            return True
    return False

Đáp án và giải thích từng bước

Hàm trả True ngay khi gặp một số dương. Với [3, −1, 5]: gặp 3 → True (sai, vì có −1). Với [4, 6]: True (đúng).

Tư duy đúng: “tất cả dương” nghĩa là không có phần tử nào không dương.

Sửa: for x in a: if x <= 0: return False rồi return True ở ngoài vòng lặp; hoặc return all(x > 0 for x in a).

Kết quả thật
True True False
TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • def tên(tham_số):; return trả giá trị và kết thúc hàm; thiếu return → None.
  • print chỉ hiện, return mới trả về.
  • Tham số: vị trí, theo tên, mặc định (đặt sau cùng), *args.
  • Biến cục bộ che biến toàn cục; sửa toàn cục cần global, hàm lồng cần nonlocal.
  • Tham số list bị sửa tại chỗ thì list bên ngoài đổi; số, xâu thì không.
  • Mặc định list rỗng là bẫy: dùng None.

Bẫy thường gặp

  • Đối số được tính từ trái sang phải.
