Bài toán sắp xếp

Vì sao quan trọng?

Sắp xếp là bước chuẩn bị cho nhiều bài: tìm nhị phân, ghép cặp, tham lam, loại trùng, tìm trung vị.

Quy ước: sắp xếp tăng dần (không giảm). Kết quả cùng các phần tử, chỉ đổi thứ tự.

Ba thuật toán cơ bản O(n²) dễ hiểu; thuật toán nhanh O(n log n).

Ví dụ
Truoc: [29, 10, 14, 37, 13]
Sau  : [10, 13, 14, 29, 37]
Giá trị cần quan sát khi học: trạng thái mảng sau mỗi lượt.

Sắp xếp chọn (Selection sort)

Ý tưởng

  1. Với mỗi vị trí i từ đầu: tìm phần tử nhỏ nhất trong đoạn [i..cuối].
  2. Đổi chỗ nó với a[i].
  3. Phần đầu mảng đã đúng vị trí tăng dần.
Số phép so sánh luôn n(n−1)/2 (không phụ thuộc dữ liệu); đổi chỗ tối đa n − 1.
def chon(a):
    for i in range(len(a) - 1):
        m = i
        for j in range(i + 1, len(a)):
            if a[j] < a[m]:
                m = j
        a[i], a[m] = a[m], a[i]
    return a

Sắp xếp nổi bọt (Bubble sort)

Ý tưởng

  1. Duyệt các cặp kề nhau (j, j+1).
  2. Nếu sai thứ tự thì đổi chỗ.
  3. Sau mỗi lượt, phần tử lớn nhất “nổi” về cuối đoạn xét.
  4. Có cờ dừng sớm: nếu một lượt không đổi chỗ thì xong.
def noi_bot(a):
    dem = 0
    for i in range(len(a) - 1):
        doi = False
        for j in range(len(a) - 1 - i):
            dem += 1
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                doi = True
        if not doi:
            break
    return dem

Sắp xếp chèn (Insertion sort)

Như xếp bài trên tay

  1. Phần đầu a[0..i−1] đã sắp xếp.
  2. Lấy x = a[i], dịch các phần tử lớn hơn x sang phải một bước.
  3. Chèn x vào chỗ trống.
Tốt nhất O(n) (đã sắp xếp); xấu nhất O(n²) (ngược). Ổn định và rất nhanh với mảng gần sắp xếp.
def chen(a):
    for i in range(1, len(a)):
        x = a[i]
        j = i - 1
        while j >= 0 and a[j] > x:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = x
    return a

Tính ổn định (stable)

Định nghĩa

Sắp xếp ổn định: hai phần tử có khoá bằng nhau giữ nguyên thứ tự ban đầu.

Quan trọng khi sắp xếp theo nhiều tiêu chí lần lượt (ví dụ: theo điểm, bằng điểm thì giữ thứ tự theo tên đã xếp trước).

Ổn định: chèn, nổi bọt (với >), trộn, sort() của Python, đếm phân phối. Không ổn định: chọn (đổi chỗ xa), nhanh, vun đống.

a = [(2, "a"), (2, "b"), (1, "c")]
b = a[:]
for i in range(len(b)):
    m = i
    for j in range(i + 1, len(b)):
        if b[j][0] < b[m][0]:
            m = j
    b[i], b[m] = b[m], b[i]
print(b)
c = sorted(a, key=lambda p: p[0])
print(c)
Chọn: (2,a) và (2,b) bị đảo; sorted: giữ thứ tự
[(1, 'c'), (2, 'b'), (2, 'a')]
[(1, 'c'), (2, 'a'), (2, 'b')]
PYTHON 6B · 5

Vì sao chọn mất ổn định?

Phân tích từng bước

[(2,a), (2,b), (1,c)]: lượt i = 0: nhỏ nhất là (1,c) ở vị trí 2; đổi a[0] ↔ a[2] → [(1,c), (2,b), (2,a)].

Phần tử (2,a) bị đưa ra sau (2,b): thứ tự tương đối của hai khoá 2 đã bị đảo.

Sắp xếp chèn chỉ dịch các phần tử lớn hơn hẳn (>), nên giữ nguyên thứ tự khi bằng nhau.

a = [(2, "a"), (2, "b"), (1, "c")]
c = a[:]
for i in range(1, len(c)):
    x = c[i]
    j = i - 1
    while j >= 0 and c[j][0] > x[0]:
        c[j + 1] = c[j]
        j -= 1
    c[j + 1] = x
print(c)
Chèn: ổn định
[(1, 'c'), (2, 'a'), (2, 'b')]
Đáp án đề: chọn → c, b, a; chèn → c, a, b.

Sắp xếp trộn (Merge sort): chia để trị

Ý tưởng

  1. Chia mảng làm hai nửa.
  2. Sắp xếp từng nửa (đệ quy).
  3. Trộn hai nửa đã sắp xếp thành một (so sánh đầu hai dãy).
Chiều sâu log₂ n, mỗi tầng trộn O(n) → O(n log n) luôn luôn. Ổn định; bộ nhớ phụ O(n).
def tron(a):
    if len(a) <= 1:
        return a
    m = len(a) // 2
    t, p = tron(a[:m]), tron(a[m:])
    kq = []
    while t and p:
        nua = t if t[0] <= p[0] else p
        kq.append(nua.pop(0))
    return kq + t + p
print(tron([29, 10, 14, 37, 13, 5]))

Sắp xếp đếm phân phối (Counting sort)

Khi giá trị nhỏ

Nếu giá trị nguyên nằm trong [0, V] và V không quá lớn: đếm số lần xuất hiện từng giá trị rồi xuất ra theo thứ tự.

Thời gian O(n + V) — nhanh hơn O(n log n) khi V nhỏ (ví dụ điểm 0..10, tuổi 0..120).

a = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]
V = 9
cnt = [0] * (V + 1)
for x in a:
    cnt[x] += 1
kq = []
for v in range(V + 1):
    kq += [v] * cnt[v]
print(cnt)
print(kq)
Kết quả

[1, 1, 2, 3, 3, 4, 5, 5, 5, 6, 9]
Không dựa trên so sánh nên vượt giới hạn n log n của sắp xếp so sánh.

sort() và sorted() trong Python

Cách dùng chuyên nghiệp

a.sort(): sửa tại chỗ, trả None; sorted(a): danh sách mới.

Thuật toán Timsort: O(n log n) xấu nhất, O(n) khi đã gần sắp xếp, ổn định.

key: hàm cho khoá; reverse=True: giảm dần.

Sắp xếp theo nhiều tiêu chí: key trả về tuple.

hs = [("An", 8), ("Binh", 9), ("Chi", 8), ("Dung", 9)]
print(sorted(hs, key=lambda p: (-p[1], p[0])))
print(sorted(hs, key=lambda p: p[1], reverse=True))
ds = ["b2", "a10", "a2"]
print(sorted(ds))
print(sorted(ds, key=lambda s: (s[0], int(s[1:]))))
Kết quả

Dòng 2: reverse=True vẫn giữ thứ tự ban đầu khi bằng điểm (An, Chi) vì ổn định.

Tự kiểm tra: sau 2 lượt của sắp xếp chọn

Câu hỏi

Với a = [29, 10, 14, 37, 13], sau đúng 2 lượt (i = 0 và i = 1) của sắp xếp chọn, a bằng gì?

a = [29, 10, 14, 37, 13]
for i in range(2):
    m = i
    for j in range(i + 1, len(a)):
        if a[j] < a[m]:
            m = j
    a[i], a[m] = a[m], a[i]
print(a)

Đáp án và giải thích từng bước

Lượt 0: nhỏ nhất 10 (vị trí 1); đổi a[0] ↔ a[1] → [10, 29, 14, 37, 13].

Lượt 1: nhỏ nhất trong [29, 14, 37, 13] là 13 (vị trí 4); đổi a[1] ↔ a[4] → [10, 13, 14, 37, 29].

Tự kiểm tra (HSG): đếm cặp nghịch thế

Câu hỏi

Cặp (i < j) mà a[i] > a[j] gọi là nghịch thế. Với a = [3, 1, 4, 2], có bao nhiêu? Liên hệ số lần đổi chỗ của sắp xếp nổi bọt/chèn.

a = [3, 1, 4, 2]
t = sum(1 for i in range(4) for j in range(i + 1, 4) if a[i] > a[j])
print(t)

Đáp án và giải thích từng bước

Các nghịch thế: (3,1), (3,2), (4,2) → 3.

Mỗi lần đổi hai phần tử kề sai thứ tự loại đúng một nghịch thế, nên số lần đổi chỗ của nổi bọt = số nghịch thế; số phần tử dịch của chèn cũng bằng nó.

Mảng ngược hoàn toàn n phần tử có n(n−1)/2 nghịch thế (xấu nhất).

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • Chọn: mỗi lượt đưa phần tử nhỏ nhất về đầu; so sánh luôn n(n−1)/2; không ổn định.
  • Nổi bọt: đổi các cặp kề; có cờ dừng sớm nên tốt nhất O(n).
  • Chèn: giữ phần đầu đã sắp xếp; tốt với mảng gần sắp xếp; ổn định.
  • Ba thuật toán trên O(n²), bộ nhớ phụ O(1).
  • Trộn O(n log n) ổn định; đếm phân phối O(n + V).
  • sort/sorted: Timsort O(n log n), ổn định, có key.

NÂNG CAO

Điều dễ nhầm và mở rộng

Bẫy thường gặp

  • Chạy đúng số lượt đề yêu cầu, không chạy hết.
  • Số so sánh nổi bọt có dừng sớm phụ thuộc dữ liệu.
  • sorted(..., reverse=True) vẫn giữ tính ổn định.
  • n = 10⁵ phải dùng sort(), không tự viết O(n²).

Mở rộng

  • Sắp xếp nhanh (quicksort), vun đống (heapsort).
  • Radix sort.
  • Sắp xếp ngoài (dữ liệu lớn hơn RAM).
