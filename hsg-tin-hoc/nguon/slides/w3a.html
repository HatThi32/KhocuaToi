CSS là gì và để làm gì?

Cascading Style Sheets

CSS là ngôn ngữ định dạng, trình bày trang web: màu sắc, phông chữ, khoảng cách, bố cục.

Tách nội dung (HTML) khỏi hình thức (CSS): sửa một tệp CSS thì cả website đổi giao diện.

CSS 3A · 1

Ba cách nhúng CSS

Inline, internal, external

Inline: thuộc tính style trong thẻ, chỉ ảnh hưởng thẻ đó.

Internal: thẻ <style> trong head, dùng cho một trang.

External: tệp .css riêng, nối bằng <link> trong head; dùng chung nhiều trang.

<!-- inline -->
<p style="color:red">A</p>

<!-- internal -->
<style> p {color:red} </style>

<!-- external -->
<link rel="stylesheet" href="style.css">
Muốn một tệp CSS dùng chung cho nhiều trang: external bằng thẻ link.

CSS 3A · 2

Cú pháp một quy tắc CSS

Bộ chọn { thuộc tính: giá trị; }

Bộ chọn: chọn phần tử cần định dạng.

Khối khai báo trong { }; mỗi khai báo là thuộc tính: giá trị; (dấu : giữa, dấu ; cuối).

Chú thích CSS: /* ghi chú */.

h1 {
  color: red;
  text-align: center;
}

/* đúng */  p { font-size: 18px; }
/* sai  */  p ( font-size = 18px )
Cú pháp đúng: p { font-size: 18px; }; không dùng ngoặc tròn hay dấu =.
CSS 3A · 2

Kế thừa

Con thừa hưởng từ cha

Nhiều thuộc tính (color, font-family, font-size, text-align…) được kế thừa: định dạng áp cho phần tử cha sẽ áp cho con, cháu.

Phần tử có định dạng riêng thì dùng của nó.

Thuộc tính margin, padding, border, background thì không kế thừa.

body { color: blue; }
h1   { color: red; }
trang-mau.html
h2 và p kế thừa xanh từ body; h1 có quy tắc riêng nên đỏ.
CSS 3A · 2

Thứ tự cuối cùng (cascading)

Cùng bộ chọn: cái sau thắng

Hai quy tắc cùng bộ chọn (cùng trọng số): quy tắc đứng sau được áp dụng.

Thuộc tính không bị ghi đè vẫn giữ nguyên.

h1 { color: red; text-align: center; }
h1 { text-align: left; }
trang-mau.html
Kết quả h1: chữ đỏ (color giữ) và căn trái (text-align bị ghi đè).

CSS 3A · 3

text-align, text-indent, line-height

Ba thuộc tính cho đoạn văn

text-align: center căn giữa (áp cho phần tử khối chứa chữ).

text-indent: 2em: thụt vào dòng đầu tiên.

line-height: 1.8: tăng khoảng cách dòng.

p {
  text-align: justify;
  text-indent: 2em;
  line-height: 1.8;
}

CSS 3A · 3

Đơn vị độ dài

Tuyệt đối và tương đối

px (pixel): cố định theo màn hình.

em: tương đối theo cỡ chữ của phần tử (1em = cỡ chữ hiện tại).

rem: theo cỡ chữ của html. %: theo phần tử cha.

Đơn vị tương đối giúp trang co giãn theo thiết bị.

CSS 3A · 4

Biểu diễn màu trong CSS

Bốn cách viết màu

Tên màu: red, blue, green…

Thập lục phân: #RRGGBB (mỗi cặp 00–FF).

rgb(r,g,b): mỗi kênh 0–255.

hsl(h,s,l): sắc độ, bão hoà, sáng.

MàuTênHexrgb
đỏred#FF0000rgb(255,0,0)
xanh lálime#00FF00rgb(0,255,0)
xanh dươngblue#0000FFrgb(0,0,255)
trắngwhite#FFFFFFrgb(255,255,255)
đenblack#000000rgb(0,0,0)
Đỏ = #FF0000 = rgb(255,0,0); xanh lá = #00FF00; xanh dương = #0000FF.
CSS 3A · 4

Màu chữ và màu nền

color và background-color

color: màu chữ.

background-color: màu nền.

background-image: url(…): ảnh nền.

Chọn màu chữ và nền tương phản để dễ đọc.

h2 {
  color: #FFFFFF;
  background-color: #1565C0;
  padding: 8px;
}

CSS 3A · 5

Tự kiểm tra: kế thừa

Câu hỏi

Với CSS dưới đây, thẻ h2 và p trong body có màu chữ gì? Vì sao?

body { color: blue; }
h1 { color: red; }

Đáp án và giải thích từng bước

h2 và p không có quy tắc riêng nên kế thừa màu xanh từ body.

Chỉ h1 được chọn trực tiếp nên màu đỏ.

CSS 3A · 5

Tự kiểm tra: thứ tự cuối cùng

Câu hỏi

Kết quả hiển thị của h1 (màu, căn lề)?

h1 { color: red; text-align: center; }
h1 { text-align: left; }

Đáp án và giải thích từng bước

Cùng bộ chọn → quy tắc sau thắng với thuộc tính trùng: text-align: left.

color: red không bị ghi đè nên giữ nguyên: chữ đỏ, căn trái.

CSS 3A · 5

Tự kiểm tra (HSG): đúng hay sai?

Câu hỏi

(a) Tệp CSS ngoài dùng chung cho nhiều trang. (b) p ( color = red ) là cú pháp đúng. (c) rgb(255,0,0) là đỏ. (d) text-indent: 2em thụt dòng đầu của đoạn. (e) margin được kế thừa từ phần tử cha.

Đáp án và giải thích từng bước

(a) Đúng.

(b) Sai: phải là p { color: red; }.

(c) Đúng.

(d) Đúng.

(e) Sai: margin không kế thừa.

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • CSS tách nội dung và trình bày.
  • Ba cách nhúng: inline, internal, external; external dùng chung nhiều trang.
  • Cú pháp: bộ chọn { thuộc tính: giá trị; }.
  • Kế thừa: con nhận từ cha; thứ tự cuối cùng: cùng trọng số, sau thắng.
  • Văn bản: font-*, color, text-align, text-indent, line-height.
  • Màu: tên, #RRGGBB, rgb(), hsl().
