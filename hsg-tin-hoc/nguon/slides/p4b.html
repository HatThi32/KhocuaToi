try – except: bắt ngoại lệ

Cách hoạt động

  1. Chạy khối try.
  2. Không lỗi: bỏ qua mọi except.
  3. Có lỗi: dừng ngay tại dòng lỗi, nhảy tới except khớp loại lỗi.
Các dòng trong try sau dòng gây lỗi không chạy.
try:
    x = int(input())
    print(10 // x)
except ValueError:
    print("khong phai so")
except ZeroDivisionError:
    print("chia cho 0")

else và finally

Thứ tự đầy đủ

  • try: đoạn có thể lỗi.
  • except: chạy khi có lỗi khớp.
  • else: chạy khi không có lỗi.
  • finally: luôn chạy, kể cả khi có return hoặc lỗi.
def chia(a, b):
    try:
        r = a // b
    except ZeroDivisionError:
        return "loi"
    else:
        return r
    finally:
        print("xong", end=" ")
print(chia(7, 2), chia(1, 0), chia(9, 3))
Kết quả
xong xong xong 3 loi 3
finally chạy 3 lần (in “xong” trước khi print trả giá trị); print ngoài in 3 loi 3.

assert: khẳng định điều kiện

Cú pháp

assert điều_kiện, "thông báo": nếu điều kiện sai thì phát sinh AssertionError.

Dùng để kiểm thử hàm: khẳng định kết quả mong đợi.

Khi test đạt thì chương trình chạy bình thường, không in gì.

def tb(a):
    return sum(a) / len(a)
kq = []
for t in ([2, 4], [], [5]):
    try:
        assert len(t) > 0, "rong"
        kq.append(tb(t))
    except AssertionError as e:
        kq.append(str(e))
print(kq)

Bộ test bắt lỗi của find_max

Các lỗi có thể mắc

  • (1) Khởi tạo m = 0 → sai khi mọi số âm.
  • (2) Bỏ sót phần tử cuối (range(len−1)).
  • (3) Nhầm dấu so sánh (< thay >).

Cần ít nhất các test: toàn số âm, max ở cuối, max ở đầu, một phần tử.

def find_max(a):
    m = a[0]
    for x in a:
        if x > m:
            m = x
    return m

tests = [([-5, -2, -9], -2), ([1, 9], 9),
         ([9, 1], 9), ([7], 7)]
for a, kq in tests:
    print(find_max(a) == kq, end=" ")
Hàm đúng: mọi test đạt
True True True True
Thử với phiên bản sai m = 0: test toàn âm trả 0 ≠ −2 → bị phát hiện.

Bộ test bắt lỗi của index_of

Hàm tìm vị trí

def index_of(a, k):
    for i in range(len(a)):
        if a[i] == k:
            return i
    return -1

Các lỗi có thể: bỏ sót phần tử cuối; bỏ sót phần tử đầu; trả về vị trí cuối thay vì vị trí đầu khi có trùng; không trả −1.

tests = [([5, 6, 7], 5),   # đầu
         ([5, 6, 7], 7),   # cuối
         ([5, 6, 5], 5),   # trùng: kỳ vọng 0
         ([5, 6, 7], 9),   # không có: -1
         ([], 1)]          # rỗng
def index_of(a, k):
    for i in range(len(a)):
        if a[i] == k:
            return i
    return -1
print([index_of(a, k) for a, k in tests])
Kết quả: mong đợi [0, 2, 0, −1, −1]

Lỗi “lệch một” (off-by-one)

Hàm đếm số chẵn bị sai

def dem_chan(a):
    dem = 0
    for i in range(len(a) - 1):
        if a[i] % 2 == 0:
            dem += 1
    return dem

Lỗi: range(len(a) − 1) chỉ chạy i = 0 … n−2, bỏ sót phần tử cuối.

Sửa: range(len(a)), hoặc duyệt trực tiếp for x in a.

Hàm sai: mong đợi 3 và 1
2 0
Test lộ lỗi: số chẵn nằm ở cuối dãy. Luôn có test mà đáp án phụ thuộc vào phần tử cuối.

Lỗi biên trong kiểm tra nguyên tố

Hàm sai với vài số đầu

def nt(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5)):
        if n % i == 0:
            return False
    return True

Lỗi: range(2, int(√n)) không lấy int(√n). Với n = 4, 9, 25… (bình phương số nguyên tố) bỏ sót ước √n → kết luận sai là nguyên tố.

Sửa: range(2, int(n ** 0.5) + 1).

Danh sách bị lẫn hợp số 4, 9, 25
[2, 3, 4, 5, 6, 7, 8, 9, 11, 13, 15, 17, 19, 23, 25, 29]
Bộ test cần các số chính phương (4, 9, 25) và các số bé (1, 2, 3).

Lỗi chỉ số và logic trong xâu đối xứng

Hàm sai hai chỗ

def la_palindrome(s):
    t = s.replace(" ", "")
    for i in range(len(t) // 2):
        if t[i] == t[len(t) - i]:
            return False
    return True

Lỗi 1: t[len(t) − i] với i = 0 → t[len(t)]: IndexError. Phải là t[len(t) − 1 − i].

Lỗi 2: điều kiện ngược: hai kí tự đối xứng bằng nhau là tốt, phải return False khi khác nhau.

Vòng lặp vô hạn trong tìm kiếm nhị phân

Hàm sai: có lúc không dừng

def tim(a, k):
    l, r = 0, len(a) - 1
    while l <= r:
        m = (l + r) // 2
        if a[m] == k:
            return m
        elif a[m] < k:
            l = m
        else:
            r = m - 1
    return -1

Lỗi: l = m không loại m khỏi khoảng tìm. Với a = [1, 3], k = 3... khi l = m thì khoảng không thu hẹp → lặp vô hạn.

Sửa: l = m + 1 (m đã xét, bỏ đi).

Hàm đã sửa
3 -1
Quy tắc: mỗi vòng lặp phải thu hẹp miền tìm; luôn ±1 sau khi đã xét m.

def tong_chan(a):

Tự kiểm tra: thứ tự try – except – finally

Câu hỏi

Chương trình in ra gì? Nếu thay int("7") bằng int("x") thì sao?

try:
    a = [1, 2, 3]
    x = int("7")
    y = a[x]
    print("A")
except ValueError:
    print("B")
except IndexError:
    print("C")
finally:
    print("D")

Đáp án và giải thích từng bước

Ban đầu: x = 7; a[7] gây IndexError → nhánh C, rồi finally D. In: C D.

Nếu int("x"): gây ValueError ngay → nhánh B, rồi finally D. In: B D. Dòng “A” không bao giờ in vì luôn có lỗi trước.

Kết quả thật với int("x")

Tự kiểm tra (HSG): chọn bộ test

Câu hỏi

Hàm đếm số lần xuất hiện lớn nhất của một giá trị liên tiếp trong dãy. Hãy nêu 5 test để phát hiện nhiều lỗi nhất.

def dai_nhat(a):
    best = cur = 1
    for i in range(1, len(a)):
        cur = cur + 1 if a[i] == a[i - 1] else 1
        best = max(best, cur)
    return best

Đáp án và giải thích từng bước

Test 1 [5]: một phần tử → 1 (hàm cho 1, nhưng dãy rỗng sẽ lỗi IndexError ở chỗ khác).

Test 2 [2,2,2,2]: toàn bằng nhau → 4 (dãy dài nhất ở cuối).

Test 3 [1,2,3]: không có cặp bằng nhau → 1.

Test 4 [3,3,1,1,1,2]: dãy dài nhất ở giữa → 3.

Test 5 [1,1,1,2,2]: dài nhất ở đầu → 3. Thêm [] (rỗng): cần quy ước kết quả 0.

Kết quả thật
1 4 1 3 3
TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • Ngoại lệ: IndexError, KeyError, ValueError, ZeroDivisionError, TypeError, NameError.
  • try chạy; có lỗi → except khớp đầu tiên; không lỗi → else; finally luôn chạy.
  • raise tự phát sinh lỗi; assert khẳng định điều kiện.
  • Bộ test: bình thường, biên, đặc biệt.
  • Lỗi hay gặp: lệch một, thiếu +1 ở range, biên > và >=, vòng lặp không thu hẹp.
  • Gỡ lỗi: đọc lỗi → tái hiện → theo dõi → sửa một chỗ → test lại.
