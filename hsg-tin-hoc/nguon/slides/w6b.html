JavaScript làm gì trong trang web?

Ngôn ngữ của trình duyệt

JavaScript (JS) thêm hành vi cho trang: phản ứng khi bấm nút, kiểm tra biểu mẫu, đổi nội dung mà không tải lại trang.

Nhúng vào HTML bằng <script> (trong trang hoặc tệp .js ngoài).

Có thể chạy ngoài trình duyệt bằng Node.js (dùng cho các ví dụ ở đây).

<button id="b">Bấm</button>
<script>
  document.getElementById("b")
    .onclick = () => alert("Chào!");
</script>
HTML cấu trúc, CSS trình bày, JavaScript hành vi.

Khai báo biến: let, const, var

Ba cách

let: biến đổi được, phạm vi khối { }.

const: hằng, không gán lại, phạm vi khối.

var (cũ): phạm vi hàm, bị hoisting; nên tránh.

Kiểu: number, string, boolean, null, undefined, object, array.

let n = 5;
const PI = 3.14;
var s = "cũ";
n = n + 1;      // đúng
// PI = 3;      // lỗi
Dùng const mặc định, let khi cần đổi giá trị; hạn chế var.

var trong vòng lặp với setTimeout

var out = [];
for (var i = 0; i < 3; i++) {
  setTimeout(() => out.push(i), 0);
}

DOM: chọn phần tử

Cây phần tử trong JS

document.querySelector(selector): chọn phần tử ĐẦU TIÊN khớp bộ chọn CSS.

querySelectorAll: tất cả phần tử khớp.

getElementById: theo id.

Đổi nội dung: .textContent, .innerHTML; đổi kiểu: .style.

const t = document.querySelector(".note");
t.textContent = "Đã đổi";
t.style.color = "red";
Chọn phần tử đầu tiên khớp bộ chọn CSS: querySelector.

Sự kiện (event)

Phản ứng với người dùng

click: bấm; input: đang gõ; change: giá trị đổi và rời khỏi ô; submit: gửi biểu mẫu.

Gắn bằng addEventListener.

const o = document.querySelector("input");
o.addEventListener("change", () => {
  console.log("đã đổi:", o.value);
});
Người dùng đổi giá trị ô input và rời khỏi ô: sự kiện change.

localStorage: lưu dữ liệu giữa các lần mở trang

Lưu trong trình duyệt

Đối tượng window.localStorage (viết localStorage) có setItem(khoá, giá trị), getItem(khoá), removeItem.

Dữ liệu còn lại khi đóng trang; chỉ lưu chuỗi.

localStorage.setItem("ten", "An");
const t = localStorage.getItem("ten");

// lưu đối tượng:
localStorage.setItem("d",
   JSON.stringify({a:1}));
Dữ liệu chỉ lưu chuỗi: dùng JSON.stringify / JSON.parse cho đối tượng.

Tự kiểm tra (HSG): đúng hay sai?

Câu hỏi

(a) typeof null là "object". (b) sort() sắp số đúng thứ tự số học. (c) for…of duyệt giá trị. (d) querySelector chọn tất cả phần tử khớp. (e) change xảy ra khi đổi giá trị và rời ô.

Đáp án và giải thích từng bước

(a) Đúng.

(b) Sai: sắp theo chuỗi.

(c) Đúng.

(d) Sai: chỉ phần tử đầu tiên.

(e) Đúng.

TRỌNG TÂM

Những điều phải nhớ

  • map biến đổi, filter lọc, reduce gộp; sort mặc định theo chuỗi.
  • for…in khoá, for…of giá trị.
  • querySelector phần tử đầu tiên; change; localStorage lưu chuỗi.
