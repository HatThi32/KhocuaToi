Vì sao cần rẽ nhánh?

Tình huống đời thường

“Nếu trời mưa thì mang ô, nếu không thì thôi.” Cuộc sống luôn có lựa chọn tuỳ điều kiện.

Chương trình cũng vậy: tuỳ dữ liệu mà làm việc này hay việc khác. Đó là cấu trúc rẽ nhánh.

Máy kiểm tra một điều kiện: kết quả True thì chạy nhánh này, False thì chạy nhánh khác.

Sơ đồ khối: hình thoi là điều kiện

if-elif-else: nhiều trường hợp, xét từ trên xuống

Cách máy làm

  1. Xét điều kiện if đầu tiên.

Điều kiện phức: and, or, not

Nhắc lại và dùng trong if

  • and: cả hai cùng đúng.
  • or: ít nhất một đúng.
  • not: phủ định.
  • So sánh dây: 3 <= x <= 10.
  • Ưu tiên: not › and › or; nghi ngờ thì dùng ngoặc.
x = int(input())
if 3 <= x <= 10:
    print("trong doan")
if x < 3 or x > 10:
    print("ngoai doan")
if x > 0 and x % 2 == 0:
    print("chan duong")

Bài mẫu 2: phương trình bậc hai

Phân tích

Với a ≠ 0, tính Δ = b² − 4ac.

Δ < 0: vô nghiệm; Δ = 0: nghiệm kép x = −b/(2a); Δ > 0: hai nghiệm x = (−b ± √Δ)/(2a).

Cần import math để dùng math.sqrt.

Tính tay x² − 5x + 6 = 0: Δ = 1 → x = 3 và 2.

import math
a, b, c = map(float, input().split())
d = b * b - 4 * a * c
if d < 0:
    print("Vo nghiem")
elif d == 0:
    print("Nghiem kep", -b / (2 * a))
else:
    r = math.sqrt(d)
    print((-b + r) / (2 * a), (-b - r) / (2 * a))

Bài mẫu 3: phân loại tam giác

Phân tích

  1. Có là tam giác? Cả ba cạnh > 0 và tổng hai cạnh bất kì > cạnh còn lại.
  2. Nếu hợp lệ: đều (ba cạnh bằng nhau), cân (có hai cạnh bằng nhau), vuông (a² + b² = c² với c lớn nhất), còn lại thường.
  3. Sắp xếp ba cạnh trước để c là lớn nhất.
a, b, c = sorted(map(int, input().split()))
if a <= 0 or a + b <= c:
    print("Khong phai tam giac")
elif a == b == c:
    print("Deu")
elif a == b or b == c:
    print("Can")
elif a * a + b * b == c * c:
    print("Vuong")
else:
    print("Thuong")
Kết quả (5 3 4)
5 3 4
Vuong
Sau sorted: a ≤ b ≤ c nên chỉ cần kiểm a + b > c. Thứ tự các nhánh quan trọng: đều trước cân.

Bài mẫu 4: tiền điện bậc thang

Đề bài và phân tích

Giá: 100 kWh đầu 2000 đ/kWh; từ 101 đến 200 2500 đ/kWh; trên 200 3000 đ/kWh. Nhập số kWh k, tính tiền.

Mỗi bậc chỉ tính cho phần điện nằm trong bậc đó. Tính tay k = 250: 100×2000 + 100×2500 + 50×3000 = 200 000 + 250 000 + 150 000 = 600 000.

k = int(input())
if k <= 100:
    t = k * 2000
elif k <= 200:
    t = 100 * 2000 + (k - 100) * 2500
else:
    t = 100 * 2000 + 100 * 2500 + (k - 200) * 3000
print(t)

Bài mẫu 5: số ngày trong tháng

Phân tích

Tháng 1, 3, 5, 7, 8, 10, 12: 31 ngày. Tháng 4, 6, 9, 11: 30 ngày.

Tháng 2: 29 ngày nếu năm nhuận, ngược lại 28.

t, n = map(int, input().split())
if t in (1, 3, 5, 7, 8, 10, 12):
    print(31)
elif t in (4, 6, 9, 11):
    print(30)
elif n % 400 == 0 or (n % 4 == 0 and n % 100 != 0):
    print(29)
else:
    print(28)
