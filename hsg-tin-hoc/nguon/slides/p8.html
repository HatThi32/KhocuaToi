Ngăn xếp: vào sau, ra trước (LIFO)

Hình dung chồng đĩa

Chỉ thao tác ở một đầu gọi là đỉnh.

push(x): đặt x lên đỉnh. pop(): lấy phần tử ở đỉnh. top: xem đỉnh. rỗng?: kiểm tra.

Phần tử vào sau thì ra trước: Last In – First Out.

Ngăn xếp có 3 phần tử: a, b, c

Cài đặt ngăn xếp bằng list

Đúng các thao tác

  • push: st.append(x) — O(1).
  • pop: st.pop() — O(1), lấy phần tử cuối.
  • top: st[-1].
  • rỗng?: not st hoặc len(st) == 0.
st.pop() khi rỗng gây IndexError: luôn kiểm tra rỗng trước.
st = []
st.append("a")
st.append("b")
st.append("c")
print(st, st[-1])
print(st.pop(), st)
print(st.pop(), st.pop(), st)
print(not st)

Bài: kiểm tra dấu ngoặc cân bằng

Ý tưởng

  1. Gặp ngoặc mở: đẩy vào ngăn xếp.
  2. Gặp ngoặc đóng: lấy đỉnh ra, phải là ngoặc mở tương ứng.
  3. Hết xâu: ngăn xếp phải rỗng.
Quên trường hợp ngăn xếp rỗng khi gặp ngoặc đóng, và quên kiểm tra rỗng ở cuối.
def can_bang(s):
    st = []
    cap = {")": "(", "]": "[", "}": "{"}
    for c in s:
        if c in "([{":
            st.append(c)
        elif c in cap:
            if not st or st.pop() != cap[c]:
                return False
    return not st

Biểu thức hậu tố (RPN)

Toán hạng trước, toán tử sau

Trung tố 5 + (1 + 2) × 4 − 3 cần dấu ngoặc và độ ưu tiên. Hậu tố: viết toán hạng trước toán tử: 5 1 2 + 4 * + 3 -.

Tính bằng ngăn xếp: số → push; toán tử → pop hai số (b rồi a), tính a op b, push kết quả.

Phải pop b trước, rồi a: với − và / thứ tự quan trọng.
st = []
for t in "5 1 2 + 4 * + 3 -".split():
    if t in "+-*":
        b = st.pop()
        a = st.pop()
        st.append(a + b if t == "+" else a - b if t == "-" else a * b)
    else:
        st.append(int(t))
print(st[-1])

Bài Josephus: bỏ qua hai, loại người thứ ba

Đề bài

7 bạn đánh số 1..7 xếp vòng tròn. Lần lượt bỏ qua hai bạn, rồi loại bạn thứ ba; cứ thế đến khi còn một bạn. Ai còn lại?

Mô phỏng bằng deque: hai lần “đưa đầu xuống cuối”, rồi popleft (loại).

from collections import deque
q = deque(range(1, 8))
loai = []
while len(q) > 1:
    for _ in range(2):
        q.append(q.popleft())
    loai.append(q.popleft())
print(loai, q[0])
Thứ tự bị loại và người còn lại
[3, 6, 2, 7, 5, 1] 4
Thứ tự loại: 3, 6, 2, 7, 5, 1 → còn lại 4.

Mô phỏng phục vụ khách hàng

Ứng dụng thực tế

Khách đến lúc t, phục vụ mất d phút, theo thứ tự đến (FIFO).

Tính thời gian chờ mỗi khách: thời điểm bắt đầu phục vụ − thời điểm đến.

from collections import deque
den = deque([(0, 5), (2, 3), (4, 2), (10, 1)])
t = 0
wait = []
while den:
    a, d = den.popleft()
    t = max(t, a)
    wait.append(t - a)
    t += d
print(wait, sum(wait) / len(wait))

BFS: loang theo từng lớp bằng hàng đợi

Ý tưởng

Duyệt theo chiều rộng: xét đỉnh gần nguồn trước, rồi các đỉnh xa hơn một bước, hai bước…

Dùng hàng đợi: lấy đầu, thêm các láng giềng chưa thăm vào cuối.

Nhờ vậy BFS tìm đường đi ngắn nhất (số cạnh) trong đồ thị không trọng số.

from collections import deque
ke = {1: [2, 3], 2: [4], 3: [4, 5], 4: [6], 5: [6], 6: []}
d = {1: 0}
q = deque([1])
while q:
    u = q.popleft()
    for v in ke[u]:
        if v not in d:
            d[v] = d[u] + 1
            q.append(v)
print(d)
Khoảng cách từ đỉnh 1
{1: 0, 2: 1, 3: 1, 4: 2, 5: 2, 6: 3}
Đỉnh 6 cách đỉnh 1 3 bước (1→2→4→6).
PYTHON 8 · 4

BFS trên mê cung: đường đi ngắn nhất

Lưới 0/1

Ô 0 đi được, ô 1 là tường. Từ (0,0) đến (n−1, m−1), mỗi bước sang ô kề (4 hướng).

d[i][j] = số bước nhỏ nhất đến ô (i, j); −1 nếu chưa đến.

from collections import deque
g = ["0010", "0110", "0000", "1110", "0000"]
n, m = 5, 4
d = [[-1] * m for _ in range(n)]
d[0][0] = 0
q = deque([(0, 0)])
while q:
    x, y = q.popleft()
    for dx, dy in ((1,0),(-1,0),(0,1),(0,-1)):
        u, v = x + dx, y + dy
        if 0 <= u < n and 0 <= v < m and g[u][v] == "0" and d[u][v] < 0:
            d[u][v] = d[x][y] + 1
            q.append((u, v))
print(d[n-1][m-1])
Số bước ngắn nhất
7

Ngăn xếp đơn điệu: phần tử lớn hơn kế tiếp

Bài toán

Với mỗi a[i], tìm phần tử đầu tiên bên phải lớn hơn nó (hoặc −1).

Cách ngây thơ: O(n²). Ngăn xếp đơn điệu: O(n) — mỗi phần tử vào và ra ngăn xếp đúng một lần.

Ngăn xếp lưu chỉ số các phần tử chưa tìm được kết quả (giá trị giảm dần).

a = [2, 1, 5, 3, 6, 4]
kq = [-1] * len(a)
st = []
for i, x in enumerate(a):
    while st and a[st[-1]] < x:
        kq[st.pop()] = x
    st.append(i)
print(kq)
Kết quả
[5, 5, 6, 6, -1, -1]
Vòng while lồng trong for nhưng tổng số lần pop ≤ n → O(n).

Hàng đợi hai đầu: cửa sổ trượt lớn nhất

Bài toán “max trong mọi đoạn k”

Dãy a, với mỗi cửa sổ k phần tử liên tiếp, in giá trị lớn nhất.

Dùng deque lưu chỉ số, giữ giá trị giảm dần: bỏ cuối nếu nhỏ hơn x; bỏ đầu nếu ra khỏi cửa sổ.

Tổng thời gian O(n).

from collections import deque
a = [1, 3, -1, -3, 5, 3, 6, 7]
k = 3
dq = deque()
kq = []
for i, x in enumerate(a):
    while dq and a[dq[-1]] <= x:
        dq.pop()
    dq.append(i)
    if dq[0] <= i - k:
        dq.popleft()
    if i >= k - 1:
        kq.append(a[dq[0]])
print(kq)
Kết quả
[3, 3, 5, 5, 6, 7]

Hàng đợi ưu tiên (heapq)

Lấy phần tử nhỏ nhất ra trước

Hàng đợi ưu tiên: push bất kì, pop luôn lấy phần tử nhỏ nhất.

Cài đặt bằng đống nhị phân (heapq): push và pop đều O(log n).

Muốn lấy lớn nhất: đẩy giá trị âm.

import heapq
h = []
for x in [5, 2, 8, 1, 9]:
    heapq.heappush(h, x)
print([heapq.heappop(h) for _ in range(3)])
h2 = [-x for x in [5, 2, 8]]
heapq.heapify(h2)
print(-heapq.heappop(h2))

8
Ứng dụng: Dijkstra, ghép k danh sách, lấy k lớn nhất.

Tự kiểm tra: Josephus

Câu hỏi

7 bạn, bỏ qua hai, loại bạn thứ ba. Ai còn lại cuối cùng?

from collections import deque
q = deque(range(1, 8))
while len(q) > 1:
    for _ in range(2):
        q.append(q.popleft())
    q.popleft()
print(q[0])

Đáp án và giải thích từng bước

q = [1..7]. Vòng 1: xoay 1, 2 → [3,4,5,6,7,1,2]; loại 3 → [4,5,6,7,1,2].

Vòng 2: xoay 4, 5; loại 6 → [7,1,2,4,5]. Vòng 3: xoay 7, 1; loại 2 → [4,5,7,1].

Vòng 4: xoay 4, 5; loại 7 → [1,4,5]. Vòng 5: xoay 1, 4; loại 5 → [1,4]. Vòng 6: xoay 1, 4 → [1,4] (hai lần xoay về nguyên); loại 1 → [4].

Người còn lại: 4.

Tự kiểm tra (HSG): kiểm tra ngoặc

Câu hỏi

Hàm can_bang có đúng không với xâu “())”? Và với “((” ? Hãy chỉ ra hai lỗi nếu thiếu hai điều kiện nhất định.

def can_bang(s):
    st = []
    cap = {")": "(", "]": "[", "}": "{"}
    for c in s:
        if c in "([{":
            st.append(c)
        elif c in cap:
            if not st or st.pop() != cap[c]:
                return False
    return not st
print(can_bang("())"), can_bang("(("))

Đáp án và giải thích từng bước

“())”: push (, pop → rỗng, gặp ) nữa: st rỗng nên not st đúng → trả False. Nếu thiếu not st or thì st.pop() gây IndexError.

“((”: hết xâu mà st còn 2 phần tử → return not st = False. Nếu cuối hàm chỉ return True thì sai.

Kết quả thật
False False True
TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • Ngăn xếp LIFO: append/pop ở cuối list; luôn kiểm tra rỗng trước khi pop.
  • Hàng đợi FIFO: dùng deque (popleft O(1)); pop(0) của list là O(n).
  • Ngoặc cân bằng; hậu tố (pop b rồi a); Josephus bằng deque.
  • BFS = hàng đợi, đường đi ngắn nhất không trọng số; DFS = ngăn xếp/đệ quy.
  • Ngăn xếp đơn điệu và deque cửa sổ trượt đưa O(n²) về O(n).
  • heapq: hàng đợi ưu tiên O(log n).

NÂNG CAO

Điều dễ nhầm và mở rộng

Bẫy thường gặp

  • Đếm ngoặc không đủ: phải đúng thứ tự lồng.
  • Hậu tố: a op b với b pop trước.
  • Mỗi phần tử vào/ra ngăn xếp đơn điệu một lần → O(n).
  • BFS đánh dấu thăm khi đẩy vào hàng đợi.

Mở rộng

  • Dijkstra với heapq.
  • Topo sort (Kahn) bằng hàng đợi.
  • Hàng đợi vòng (circular buffer).
