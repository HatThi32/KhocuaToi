Mục tiêu và nội dung bài

Sau bài học, em có thể

  • Hiểu độ phức tạp thời gian là tốc độ tăng số phép toán theo n.
  • Nhận biết O(1), O(log n), O(n), O(n log n), O(n²), O(2ⁿ).
  • Đếm phép toán trong vòng lặp đơn, lồng, chia đôi.
  • Ước lượng thời gian chạy với n = 10⁵, 10⁶, 10⁹.
  • Chọn thuật toán phù hợp giới hạn đề bài.

Vì sao cần đo độ phức tạp?

Vấn đề

  • Một bài toán có nhiều thuật toán; thuật toán nào nhanh hơn?
  • Đo bằng giây phụ thuộc máy, ngôn ngữ.
  • Cần thước đo độc lập máy: đếm số phép toán cơ bản theo cỡ dữ liệu n.
Độ phức tạp thời gian: số phép toán cần thực hiện tăng thế nào khi n tăng, bỏ qua hằng số và số hạng bé.

Quan tâm n rất lớn: 3n + 100 và 5n đều coi là O(n).

PYTHON 5 · 1

Đếm phép toán: vòng lặp đơn

def dem(n):
    d = 0
    for i in range(n):
        d += 1
    return d

for n in [10, 100, 1000]:
    print(n, dem(n))
Một vòng lặp chạy n lần → O(n): n tăng gấp 10 thì số phép tăng gấp 10.

100 100
1000 1000

Đếm phép toán: hai vòng lồng

def dem(n):
    d = 0
    for i in range(n):
        for j in range(n):
            d += 1
    return d

for n in [10, 100, 1000]:
    print(n, dem(n))
Hai vòng lồng nhau đều chạy n lần → n × n = O(n²): n tăng 10 lần thì số phép tăng 100 lần.

Đếm phép toán: vòng lặp chia đôi

def dem(n):
    d = 0
    while n > 1:
        n //= 2
        d += 1
    return d

for n in [8, 1024, 10**6, 10**9]:
    print(n, dem(n))
Mỗi lần giảm một nửa → số lần lặp ≈ log₂ n → O(log n). Với n = 10⁹ chỉ cần khoảng 30 lượt!

Vòng lặp lồng nhưng không phải n²

def dem(n):
    d = 0
    for i in range(n):
        for j in range(i):
            d += 1
    return d

for n in [10, 100]:
    print(n, dem(n), n * (n - 1) // 2)
Tổng 0 + 1 + … + (n-1) = n(n-1)/2 ≈ n²/2 → vẫn là O(n²) (bỏ hệ số 1/2).

Quy tắc rút gọn kí hiệu O

Cách rút gọn

  • Bỏ hằng số nhân: 5n → O(n).
  • Bỏ số hạng bậc thấp: n² + 3n + 7 → O(n²).
  • Hai đoạn nối tiếp: cộng, lấy phần lớn: O(n) + O(n²) = O(n²).
  • Hai vòng lồng nhau: nhân: O(n) × O(m) = O(nm).

2n + n²/2O(n²)

Tính tổng 1..n: ba cách

def c1(n):
    s = 0
    for i in range(1, n + 1):
        s += i
    return s

def c2(n):
    return n * (n + 1) // 2

print(c1(100), c2(100))
print(c2(10**12))
Cách 1: O(n). Cách 2 dùng công thức: O(1). Với n = 10¹², cách 1 không chạy nổi, cách 2 xong tức thì.

Số nguyên tố: thử đến n hay đến √n

def thu(n):
    d = 0
    i = 2
    while i * i <= n:
        d += 1
        i += 1
    return d

n = 1000003
print("đến n-1:", n - 2)
print("đến √n:", thu(n))
Thử đến n-1: O(n) ≈ 10⁶ lượt. Thử đến √n: O(√n) ≈ 10³ lượt, cho cùng kết luận n = 1000003 là số nguyên tố.

Tìm tuần tự và tìm nhị phân

def nhi_phan(a, x):
    l, r, d = 0, len(a) - 1, 0
    while l <= r:
        d += 1
        m = (l + r) // 2
        if a[m] < x:
            l = m + 1
        else:
            r = m - 1
    return d

a = list(range(1, 100001))
print("tuần tự:", len(a))
print("nhị phân:", nhi_phan(a, 100000))
Trường hợp xấu nhất với 10⁵ phần tử: tuần tự 100 000 bước, nhị phân chỉ khoảng 17 bước.

Fibonacci: O(2ⁿ) và O(n)

def fib1(n):
    global dem
    dem += 1
    return n if n < 2 else fib1(n - 1) + fib1(n - 2)

dem = 0
print(fib1(20), dem)

def fib2(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
print(fib2(20), fib2(90))
Đệ quy ngây thơ gọi 21 891 lần cho n = 20 (tăng gần 1,6ⁿ); vòng lặp chỉ n bước.

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • Độ phức tạp = tốc độ tăng số phép toán theo n; bỏ hằng số và số hạng bé.
  • Vòng đơn O(n); lồng nhau O(n²); chia đôi O(log n).
  • Thứ tự: 1 < log n < n < n log n < n² < 2ⁿ.
  • Nối tiếp thì cộng (lấy lớn), lồng nhau thì nhân.
  • Máy làm khoảng 10⁸ phép/giây: chọn thuật toán theo giới hạn n.
Cần…Dùng
n ≤ 10⁵O(n log n)
n ≤ 10⁶O(n)
n ≤ 5000O(n²)
n ≤ 25O(2ⁿ)
Không bỏ qua vòng lặp ẩn: in trên list, sum, .index đều là O(n).
NÂNG CAO

Điều dễ nhầm và mở rộng

Bẫy thường gặp

  • x in list là O(n) nhưng x in set là O(1) (trung bình).
  • a.append O(1) nhưng a.insert(0, x) O(n).
  • sorted là O(n log n).
  • Cắt lát a[i:j] tốn O(j-i).

Mở rộng

  • Ω, Θ: cận dưới và cận chặt (mở rộng).
  • Độ phức tạp trung bình khác xấu nhất (Quick sort).
  • Đánh đổi thời gian và bộ nhớ (bảng băm, bảng tính trước).
