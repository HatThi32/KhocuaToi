Xâu là dãy kí tự có đánh chỉ số

Khái niệm

Xâu viết trong cặp nháy ' ' hoặc " ". Mỗi kí tự (kể cả dấu cách) có một chỉ số.

Chỉ số dương đếm từ 0 bên trái; chỉ số âm đếm từ −1 bên phải.

len(s) cho số kí tự; kí tự cuối có chỉ số len(s) − 1.

s = "Tin Hoc"
print(len(s), s[0], s[3] == " ", s[-1], s[-3])
print(s[7])

Cắt lát s[a:b]: lấy từ a đến b − 1

Quy tắc

s[a:b] lấy các kí tự chỉ số a, a+1, …, b − 1 (không lấy b).

Bỏ a: bắt đầu từ đầu. Bỏ b: đến hết. Chỉ số vượt phạm vi không báo lỗi khi cắt lát.

Độ dài lát cắt = b − a.

s = "Tin hoc 12 - Da Nang"
print(s[4:7])
print(s[:3])
print(s[-4:])
print(s[4:100])
print(s[5:2], len(s))

Đây chính là câu hỏi mẫu của đề: s[4:7] = “hoc”, s[-4:] = “Nang”, len = 20.

Cắt lát có bước: s[a:b:k]

Bước k

Lấy kí tự chỉ số a, a+k, a+2k, … trong khi chưa tới b.

Bước âm: đi ngược; s[::-1] là đảo ngược xâu.

Với bước âm, mặc định a = cuối, b = trước đầu.

s = "Tin Hoc 11"
print(s[::-1])
print(s[1:-1:2])
print(s[::3])

Phép toán trên xâu: +, *, in, so sánh

Các phép toán

  • a + b: nối xâu; a * 3: lặp xâu.
  • "in" in s: kiểm tra xâu con (không phân biệt vị trí).
  • So sánh < > ==: theo thứ tự từ điển (mã Unicode từng kí tự).
  • Không cộng xâu với số: phải str().
print("ab" + "cd", "ab" * 3)
print("na" in "banana", "x" in "banana")
print("apple" < "banana", "Z" < "a", "10" < "9")
print("a" + str(5), "5" * 3)

split và join

Hai phương thức đối lập

s.split(): tách theo mọi khoảng trắng liên tiếp, bỏ rỗng ở hai đầu → danh sách từ.

s.split(sep): tách theo đúng chuỗi sep; hai sep liền nhau sinh xâu rỗng.

sep.join(ds): nối các xâu trong ds, xen sep giữa.

s = "  be   dep  trai  "
a = s.split()
b = s.strip().split(" ")
print(len(a), len(b))
print("-".join(a))
print(b)

Mã kí tự: ord và chr

Nhắc lại và ứng dụng

ord(c) trả mã Unicode (ASCII) của kí tự; chr(m) làm ngược lại.

A–Z mã 65–90; a–z mã 97–122; 0–9 mã 48–57.

Chữ thường → chữ hoa cùng chữ: mã trừ 32. Vị trí trong bảng chữ cái: ord(c) − ord("a").

print(ord("A"), ord("a"), ord("0"))
print(chr(66), chr(ord("a") + 3))
print(ord("e") - ord("a"))
print("".join(chr(ord(c) - 32) for c in "tin"))

Duyệt xâu: hai cách

Theo kí tự hoặc theo chỉ số

for c in s: lấy từng kí tự — gọn, dùng khi không cần vị trí.

for i in range(len(s)): — dùng khi cần vị trí hoặc so sánh kí tự kề nhau.

for i, c in enumerate(s): — có cả hai.

s = "a1b22c333"
d = 0
for ch in s:
    if ch.isdigit():
        d += int(ch)

lien = 0

        lien += 1
print(lien)

Xâu đối xứng (palindrome)

Ba cách kiểm tra

Cách 1: s == s[::-1].

Cách 2: hai chỉ số i, j chạy vào giữa.

Thường chuẩn hoá trước: bỏ khoảng trắng, đổi chữ thường.

def dx(s):
    t = "".join(c.lower() for c in s if c.isalnum())
    return t == t[::-1]

print(dx("Level"), "Level" == "Level"[::-1])
print(dx("A man, a plan, a canal: Panama"))
print(dx("Da Nang"))
Kết quả
True False
True
False
“Level” đối xứng nếu bỏ qua hoa thường; so sánh trực tiếp thì không (L ≠ l).

Mật mã Caesar (dịch vòng k vị trí)

Ý tưởng

Mỗi chữ thường được dịch k vị trí trong bảng chữ cái, quay vòng sau z.

Công thức: chr((ord(c) − ord("a") + k) % 26 + ord("a")).

Kí tự khác chữ thường giữ nguyên.

Giải mã = mã hoá với 26 − k (hoặc −k).

def mh(s, k):
    kq = ""
    for c in s:
        if "a" <= c <= "z":
            kq += chr((ord(c) - 97 + k) % 26 + 97)
        else:
            kq += c
    return kq
print(mh("xyz abc", 3))
print(mh(mh("tin hoc", 5), 21))
Kết quả
abc def
tin hoc
Mã hoá 5 rồi 21: 5 + 21 = 26 ≡ 0 nên trở về xâu gốc.

Nén xâu: đếm các kí tự liên tiếp

Mã hoá độ dài chạy (RLE)

Chuyển “aaabccdd” thành “a3b1c2d2”: mỗi kí tự kèm số lần lặp liên tiếp.

Duyệt bằng chỉ số; nhớ kí tự trước và đếm.

Nhớ ghi nốt nhóm cuối sau vòng lặp!

s = "aaabccdd"
kq = ""
i = 0
while i < len(s):
    j = i
    while j < len(s) and s[j] == s[i]:
        j += 1
    kq += s[i] + str(j - i)
    i = j
print(kq)
Kết quả
a3b1c2d2
Hai vòng while lồng nhưng mỗi kí tự chỉ được duyệt một lần (i nhảy tới j) → tuyến tính.

Đếm tần suất kí tự bằng dict

Kĩ thuật dùng nhiều nhất

Dùng từ điển: d[c] = d.get(c, 0) + 1.

d.get(k, 0) trả 0 nếu chưa có khoá, tránh lỗi KeyError.

Kí tự xuất hiện nhiều nhất: max(d, key=d.get).

s = "tin hoc ung dung"
d = {}
for c in s:
    if c != " ":
        d[c] = d.get(c, 0) + 1
print(d)
print(max(d, key=d.get), max(d.values()))
Kết quả
{'t': 1, 'i': 1, 'n': 3, 'h': 1, 'o': 1, 'c': 1, 'u': 2, 'g': 2, 'd': 1}
n 3
Có nhiều kí tự cùng tần suất thì max chọn kí tự xuất hiện sớm nhất trong từ điển.

s = "  be   dep  trai  "

Tự kiểm tra (HSG): sai ở chỗ nào?

Câu hỏi

Hàm sau định kiểm tra “xâu chỉ gồm chữ cái, không phân biệt hoa thường, và đối xứng”. Cho kết quả với “Aba” và “ab1ba”. Có lỗi không?

def kt(s):
    return s.isalpha() and s.lower() == s[::-1]

Đáp án và giải thích từng bước

“Aba”: isalpha đúng; s.lower() = “aba”, s[::-1] = “abA” (chưa hạ chữ thường) → “aba” == “abA” là False. Lẽ ra phải là True.

“ab1ba”: isalpha False vì có chữ số → False (đúng ý).

Sửa: t = s.lower(); return s.isalpha() and t == t[::-1].

Kết quả thật
False False True
TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • Xâu là dãy bất biến, có chỉ số dương từ 0 và âm từ −1.
  • s[a:b:k] lấy từ a đến b − 1; vượt phạm vi khi cắt lát không lỗi; s[::-1] đảo xâu.
  • Phương thức xâu trả về xâu mới; find trả −1, index báo lỗi.
  • split() khác split(" "); join ghép lại.
  • ord / chr cho mã kí tự; Caesar dùng % 26.
  • Đếm tần suất bằng dict.get.
