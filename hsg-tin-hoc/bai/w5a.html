CSS 5A · 1

Mô hình hộp (box model)

Mỗi phần tử là một hộp

Từ trong ra ngoài: content (nội dung) → padding (đệm) → border (viền) → margin (lề ngoài).

padding: khoảng cách từ nội dung tới viền (nền tô cả vùng này).

margin: khoảng cách ngoài viền tới phần tử khác (trong suốt).

Thứ tự từ trong ra: content → padding → border → margin.
CSS 5A · 1

Thuộc tính border

Viền: dày – kiểu – màu

Viết tắt: border: 2px solid blue; = độ dày, kiểu, màu.

Kiểu viền: solid (liền), dashed, dotted, double, none.

Từng cạnh: border-top, border-left…

Bo góc: border-radius.

td {
  border: 2px solid blue;
}

.hop {
  border-radius: 12px;
  border-bottom: 3px dashed red;
}

CSS 5A · 3

Kích thước: content-box và border-box

box-sizing

content-box (mặc định): width chỉ là phần nội dung; tổng = width + padding + border.

border-box: width gồm cả padding và border; nội dung co lại.

Ví dụ: width 200, padding 20, border 5.

KiểuTổng chiều rộng
content-box200 + 2×20 + 2×5 = 250 px
border-box200 px (đúng bằng width)
* { box-sizing: border-box; }
Số liệu đo bằng trình duyệt thật: content-box 250 px, border-box 200 px.
CSS 5A · 3

Tính kích thước hộp: ví dụ

width 300, padding 10, border 2, margin 15

  1. content-box: rộng = 300 + 2×10 + 2×2 = 324.
  2. Chiếm chỗ ngang cả margin: 324 + 2×15 = 354.
  3. border-box: rộng hộp vẫn 300; nội dung = 300 − 20 − 4 = 276.
.hop {
  width: 300px;
  padding: 10px;
  border: 2px solid red;
  margin: 15px;
}
Đề hay hỏi: tổng chiều rộng (không gồm margin) và tổng chỗ chiếm (gồm margin).
CSS 5A · 4

Gộp lề dọc (margin collapsing)

Hai lề dọc liền kề gộp thành một

Hai khối liền kề theo chiều dọc: lề dưới của khối trên và lề trên của khối dưới gộp, khoảng cách là giá trị lớn hơn, không phải tổng.

Ví dụ: margin-bottom 30px và margin-top 20px → khoảng cách 30 px.

Chỉ gộp lề dọc; lề ngang không gộp.

.a { margin-bottom: 30px; }
.b { margin-top: 20px; }
trang-mau.html
Khoảng cách thật đo bằng trình duyệt: 30 px (= max(30, 20)), không phải 50.
CSS 5A · 5

Kiểu hiển thị: block, inline, inline-block, none

display

block: chiếm cả dòng; có thể đặt width, height, margin dọc.

inline: nằm cùng dòng; width, height không có tác dụng.

inline-block: nằm cùng dòng nhưng đặt được width, height.

none: ẩn hẳn, không chiếm chỗ (visibility:hidden vẫn chiếm chỗ).

.k { display: inline-block;
     width: 80px; }
.an { display: none; }
trang-mau.html
Phần tử biến mất và không chiếm chỗ: display: none.

CSS 5A · 6

Tự kiểm tra (HSG): đúng hay sai?

Câu hỏi

(a) Thứ tự từ trong ra: content, padding, border, margin. (b) margin: 10px 20px là trên-dưới 10, trái-phải 20. (c) visibility:hidden không chiếm chỗ. (d) inline-block đặt được width. (e) Lề dọc liền kề cộng dồn.

Đáp án và giải thích từng bước

(a) Đúng.

(b) Đúng.

(c) Sai: vẫn chiếm chỗ; display:none mới không.

(d) Đúng.

(e) Sai: gộp lại lấy giá trị lớn nhất.

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • Hộp: content → padding → border → margin.
  • border: dày kiểu màu; viết tắt 1–4 giá trị (trên phải dưới trái).
  • content-box: width chỉ nội dung; border-box: gồm padding + border.
  • Gộp lề dọc: lấy giá trị lớn nhất.
  • block chiếm dòng; inline cùng dòng; inline-block cùng dòng có kích thước; none ẩn hẳn.

Cộng hai lề dọc; quên padding/border khi tính content-box; nhầm visibility:hidden với display:none.

  • outline không chiếm chỗ.
