Dạng 1: dòng đầu là n, sau đó n dòng, mỗi dòng một số. Mỗi lần input() đọc một dòng, nên phải gọi n lần (dùng vòng lặp).

tong = 0
for _ in range(n):

print(tong)

f-string: nhúng giá trị vào câu

Cú pháp

Đặt chữ f trước dấu nháy; chỗ nào cần giá trị viết {biểu thức}.

Trong {…} có thể viết biểu thức bất kì: {a + b}, {ten.upper()}.

Dễ đọc hơn nhiều so với ghép bằng dấu + và str().

ten, tuoi = "Lan", 17
print(f"{ten} {tuoi} tuoi")
print(f"Sang nam: {tuoi + 1}")
print(f"{tuoi * 2 = }")
print("{ten}")
print(f"{{ten}}")
Kết quả chạy
Lan 17 tuoi
Sang nam: 18
tuoi * 2 = 34
{ten}
{ten}
Quên chữ f thì in nguyên văn {ten}. Muốn in dấu { } dùng {{ và }}.

Các cách định dạng khác (để đọc hiểu)

x, n = 3.14159, 7
print("%.2f" % x)
print("%d + %d" % (n, n))
print("{:.2f} - {}".format(x, n))
print("{0} {1} {0}".format("a", "b"))
print(round(x, 2))

Ba cách, cùng một việc

  • %: kiểu cũ (từ ngôn ngữ C): %d nguyên, %f thực, %s xâu.
  • .format(): kiểu trung gian.
  • f-string: nên dùng (ngắn, dễ đọc).
  • round(x, 2) trả về số (có thể bỏ số 0 cuối: 2.5), còn định dạng cho ra xâu.

Bài mẫu 1: chu vi và diện tích hình tròn

Phân tích

Đề: nhập bán kính r, in chu vi và diện tích (π = 3.14159), làm tròn 2 chữ số thập phân.

Vào: r (số thực). Ra: hai số.

Công thức: C = 2πr ; S = πr².

Tính tay với r = 2: C = 12.566… → 12.57; S = 12.566… → 12.57.

PI = 3.14159
r = float(input())
c = 2 * PI * r
s = PI * r ** 2
print(f"{c:.2f} {s:.2f}")
Chạy thử (r = 2)
2
12.57 12.57
Khớp tính tay (12.57 12.57). Dùng r ** 2 chứ không phải r * 2.

Bài mẫu 3: đổi giây ra giờ – phút – giây

Phân tích

Đề: nhập số giây s (0 ≤ s ≤ 86399), in dạng hh:mm:ss.

Cách làm: giờ = s // 3600; phút = s % 3600 // 60; giây = s % 60.

Tính tay s = 3725: 3725 // 3600 = 1; 125 // 60 = 2; 3725 % 60 = 5 → 01:02:05.

s = int(input())
gio = s // 3600
phut = s % 3600 // 60
giay = s % 60
print(f"{gio:02d}:{phut:02d}:{giay:02d}")
Chạy thử (3725)
3725
01:02:05
:02d đệm số 0 để luôn đủ 2 chữ số: 1 → 01.

Bài mẫu 5: đổi tiền và chia nguyên

Phân tích

Đề: rút số tiền n (nghìn đồng, bội của 10). In số tờ 500 nghìn, 100 nghìn, 50 nghìn, 10 nghìn ít tờ nhất.

Bài mẫu 6: BMI và so sánh logic

Phân tích

Đề: nhập cân nặng (kg) và chiều cao (m). Tính BMI = cân nặng / chiều cao². In BMI (1 chữ số thập phân) và True/False nếu thuộc khoảng bình thường 18.5 ≤ BMI < 25.

Gỡ lỗi bằng print()

Cách làm

Khi kết quả sai: in giá trị các biến ở từng bước để thấy chỗ nào lệch so với tính tay.

Ví dụ dưới có lỗi logic: muốn tính trung bình hai số nhưng cho kết quả sai.

a, b = 7, 9
tb = a + b / 2
print("b/2 =", b / 2)
print("a + b/2 =", a + b / 2)
print("(a+b)/2 =", (a + b) / 2)
Kết quả
b/2 = 4.5
a + b/2 = 11.5
(a+b)/2 = 8.0
Thấy ngay: a + b / 2 = 11.5, đúng phải là (a + b) / 2 = 8.0. Thiếu ngoặc.
