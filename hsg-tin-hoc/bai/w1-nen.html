URL và tên miền

Giao thức

http: không mã hoá. https: mã hoá (TLS) nên an toàn khi đăng nhập, thanh toán. Cổng mặc định: http 80, https 443 (thường được ẩn).

Ví dụ: https:// mã hoá, http:// thì không.

Tên miền đọc từ phải sang trái

.vn miền cấp cao quốc gia → example tên đăng kí → www máy chủ con. Máy tính chỉ dùng IP nên cần DNS.

Ví dụ: www.example.vn thuộc miền .vn.

Phần sau dấu # chỉ xử lí ở trình duyệt (nhảy tới phần tử có id), không gửi lên máy chủ.

Ví dụ: máy chủ nhận /hoc/bai1.html?lop=12, còn #muc2 ở lại trình duyệt.

NỀN

Trình duyệt tải trang như thế nào?

  1. Người dùng nhập URL hoặc nháy liên kết.
  2. Trình duyệt hỏi DNS để lấy địa chỉ IP.
  3. Thiết lập kết nối tới máy chủ (https: thêm bước mã hoá).
  4. Gửi yêu cầu HTTP: GET /hoc/bai1.html.
  5. Máy chủ gửi phản hồi: mã trạng thái + tệp HTML.
  6. Phân tích HTML, dựng cây; gặp CSS, ảnh, script thì gửi thêm yêu cầu.
  7. Áp CSS, chạy script, vẽ trang lên màn hình.

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • Internet là hệ thống mạng; Web là dịch vụ chạy trên Internet.
  • URL = giao thức + tên miền + [cổng] + đường dẫn + [?truy vấn] + [#mảnh].
  • DNS đổi tên miền thành địa chỉ IP.
  • Trình duyệt gửi yêu cầu HTTP; máy chủ trả mã trạng thái và nội dung.
MãÝ nghĩa
200Thành công
301Chuyển hướng vĩnh viễn
404Không tìm thấy tài nguyên
500Lỗi phía máy chủ
Phần #mảnh không được gửi lên máy chủ; chỉ trình duyệt dùng nó để nhảy tới phần tử có id.

URL đầy đủ và phương thức HTTP

https://tin.edu.vn:8443/lop12/bai.html?id=5&k=a#muc2
Thành phầnGiá trị
Giao thứchttps
Tên miềntin.edu.vn
Cổng8443
Đường dẫn/lop12/bai.html
Truy vấnid=5&k=a (2 tham số)
Mảnhmuc2

Kiến thức mở rộng

  • Cổng mặc định: http 80, https 443 (nên không cần viết).
  • Truy vấn gồm các cặp tên=giá trị ngăn bằng &.
  • GET: dữ liệu nằm trên URL, ai cũng thấy; POST: dữ liệu gửi trong thân yêu cầu.
  • HTTPS = HTTP có mã hoá, an toàn hơn khi gửi mật khẩu.
