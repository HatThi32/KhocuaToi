Kiểm tra ngoặc hợp lệ

def hop_le(s):
    st = []
    cap = {")": "(", "]": "[", "}": "{"}
    for ch in s:
        if ch in "([{":
            st.append(ch)
        elif ch in ")]}":
            if not st or st.pop() != cap[ch]:
                return False
    return not st

for t in ["(a+[b])", "(()", "([)]", ""]:
    print(repr(t), hop_le(t))
Gặp ngoặc mở: push. Gặp ngoặc đóng: pop và so khớp. Cuối cùng ngăn xếp phải rỗng.

Biểu thức hậu tố (RPN)

Ba cách viết biểu thức

  • Trung tố: 3 + 4
  • Hậu tố: 3 4 + (toán tử đứng sau)
  • Tiền tố: + 3 4
Hậu tố không cần ngoặc: (3+4)*5 viết 3 4 + 5 *.

Quy tắc tính: gặp số thì push; gặp toán tử thì pop hai số, tính rồi push kết quả.

PYTHON 8 · 2

Tính biểu thức hậu tố

def tinh(bt):
    st = []
    for t in bt.split():
        if t in "+-*/":
            b = st.pop()
            a = st.pop()
            st.append(a + b if t == "+" else a - b if t == "-" else a * b if t == "*" else a / b)
        else:
            st.append(float(t))
    return st[0]

print(tinh("3 4 + 5 *"))
print(tinh("5 1 2 + 4 * + 3 -"))
Chú ý thứ tự: pop b trước, rồi a (a là toán hạng trái). “5 1 2 + 4 * + 3 -” = 5 + (1+2)·4 − 3 = 14.

Bài toán Josephus (vòng tròn loại)

from collections import deque
n, k = 7, 3
q = deque(range(1, n + 1))
ra = []
while q:
    q.rotate(-(k - 1))
    ra.append(q.popleft())
print(ra)
print("còn lại cuối:", ra[-1])
n người đứng vòng tròn, cứ đếm đến k thì loại người đó. rotate xoay vòng deque để đưa người thứ k lên đầu rồi loại.

Duyệt theo lớp (BFS) trên lưới nhỏ

from collections import deque
g = {1: [2, 3], 2: [4], 3: [4, 5], 4: [6], 5: [6], 6: []}
q = deque([1])
da = {1}
thu_tu = []
while q:
    u = q.popleft()
    thu_tu.append(u)
    for v in g[u]:
        if v not in da:
            da.add(v)
            q.append(v)
print(thu_tu)
BFS (duyệt theo chiều rộng) dùng hàng đợi: thăm đỉnh gần trước, đỉnh xa sau → tìm đường đi ngắn nhất (số cạnh).

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • Ngăn xếp: LIFO; append (push), pop() (lấy đỉnh).
  • Hàng đợi: FIFO; deque.append, popleft().
  • Ngăn xếp dùng cho ngoặc, hậu tố, đệ quy, Undo.
  • Hàng đợi dùng cho mô phỏng, BFS, hàng chờ.
  • Trước khi pop/popleft phải kiểm tra không rỗng.
Cần…Dùng
Kiểm tra ngoặcstack
Duyệt theo lớp (BFS)queue
Lấy đầu hàngpopleft()
Lấy đỉnh stackpop()
pop(0) trên list chậm O(n); pop/popleft trên rỗng báo IndexError.
NÂNG CAO

Điều dễ nhầm và mở rộng

Bẫy thường gặp

  • Ngăn xếp gọi hàm là cơ chế của đệ quy.
  • Hậu tố đổi từ trung tố bằng thuật toán Dijkstra shunting-yard.
  • queue.Queue, heapq (hàng đợi ưu tiên).
  • Hàng đợi vòng cố định kích thước.

Mở rộng

  • Hàng đợi ưu tiên (heap): lấy phần tử nhỏ nhất.
  • DFS dùng ngăn xếp (hoặc đệ quy).
  • Đơn điệu stack giải bài “phần tử lớn hơn kế tiếp”.
