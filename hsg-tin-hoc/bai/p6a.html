Tìm kiếm tuần tự

Ý tưởng

  1. Xét lần lượt từng phần tử từ đầu.
  2. Gặp phần tử bằng k: trả vị trí, dừng.
  3. Hết dãy mà chưra gặp: trả −1.
Tốt nhất 1 lần, xấu nhất n lần: O(n). Không yêu cầu dãy sắp xếp.
def tim_tt(a, k):
    dem = 0
    for i in range(len(a)):
        dem += 1
        if a[i] == k:
            return i, dem
    return -1, dem

a = [7, 3, 9, 3, 5, 8]
print(tim_tt(a, 7), tim_tt(a, 3))
print(tim_tt(a, 8), tim_tt(a, 4))
(vị trí, số lần so sánh)
(0, 1) (1, 2)
(5, 6) (-1, 6)
Phần tử 3 xuất hiện hai lần: tìm tuần tự trả vị trí đầu tiên (1).

Ý tưởng tìm nhị phân

Như đoán số trong trò chơi

Dãy đã sắp xếp tăng. So k với phần tử giữa:

• bằng → tìm thấy;

• k nhỏ hơn → chỉ còn nửa trái;

• k lớn hơn → chỉ còn nửa phải.

Mỗi lần so sánh loại một nửa → chỉ cần ≈ log₂ n lần.

Mỗi bước giảm một nửa
PYTHON 6A · 2

Cài đặt tìm kiếm nhị phân

Ba biến l, r, m

l, r: hai đầu miền còn có thể chứa k. m = (l + r) // 2.

a[m] < k → l = m + 1; a[m] > k → r = m − 1.

Điều kiện lặp: l ≤ r (miền còn phần tử).

±1 là bắt buộc: m đã xét, bỏ đi. Thiếu thì lặp vô hạn.
def tim(a, k):
    l, r = 0, len(a) - 1
    dem = 0
    while l <= r:
        m = (l + r) // 2
        dem += 1
        if a[m] == k:
            return m, dem
        elif a[m] < k:
            l = m + 1
        else:
            r = m - 1
    return -1, dem
Kết quả (m, số lần so sánh)
(5, 2) (0, 3) (-1, 3)

Điều kiện: dãy phải được sắp xếp

Nhị phân trên dãy chưa sắp xếp sai!

Loại một nửa dựa trên giả thiết nửa kia chắc chắn không chứa k — đúng chỉ khi dãy tăng.

Dãy giảm thì đổi chiều so sánh. Dãy bất kì phải sắp xếp trước (O(n log n)).

# hàm tim như slide trước
b = [5, 1, 9, 3, 7]
print(tim(b, 7), tim(sorted(b), 7))
Dãy chưa sắp xếp: không tìm thấy 7 dù có
(-1, 3) (3, 2)
Nên tìm một lần thì tuần tự rẻ hơn; tìm nhiều lần thì sắp xếp một lần rồi nhị phân.
PYTHON 6A · 3

Vị trí đầu tiên khi có giá trị trùng

Không dừng khi gặp

Khi a[m] == k, ta chưa chắc m là đầu tiên. Ghi nhận kq = m rồi tiếp tục tìm bên trái (r = m − 1).

Tìm cuối cùng: ghi nhận rồi tìm bên phải (l = m + 1).

Đếm số lần xuất hiện = cuối − đầu + 1.

def dau(a, k):
    l, r, kq = 0, len(a) - 1, -1
    while l <= r:
        m = (l + r) // 2
        if a[m] == k:
            kq = m
            r = m - 1
        elif a[m] < k:
            l = m + 1
        else:
            r = m - 1
    return kq
a = [1, 2, 2, 2, 3, 5]
print(dau(a, 2), dau(a, 4))

PYTHON 6A · 3

Thư viện bisect

Có sẵn trong Python

bisect_left(a, k): vị trí đầu tiên có thể chèn k (= vị trí đầu của k nếu có).

bisect_right(a, k): vị trí sau phần tử k cuối.

Số lần k xuất hiện: bisect_right − bisect_left. Số phần tử < k: bisect_left.

from bisect import bisect_left, bisect_right
a = [1, 2, 2, 2, 3, 5]
print(bisect_left(a, 2), bisect_right(a, 2))
print(bisect_right(a, 2) - bisect_left(a, 2))
print(bisect_left(a, 4), bisect_left(a, 0))
print(bisect_right(a, 5) - bisect_left(a, 2))

Dòng cuối: số phần tử trong đoạn [2, 5] = 5.

Tìm phần tử gần nhất và các biến thể

Ứng dụng của bisect

Phần tử nhỏ nhất ≥ k (lower bound): a[bisect_left(a, k)] nếu chỉ số hợp lệ.

Phần tử lớn nhất ≤ k: a[bisect_right(a, k) − 1] nếu ≥ 0.

Nhờ vậy xử lí hàng nghìn truy vấn trong O(log n) mỗi truy vấn.

from bisect import bisect_left, bisect_right
a = [3, 8, 12, 17, 25, 31, 40]
def gan_nhat(a, k):
    i = bisect_left(a, k)
    ung = []
    if i < len(a): ung.append(a[i])
    if i > 0: ung.append(a[i - 1])
    return min(ung, key=lambda v: abs(v - k))
print(gan_nhat(a, 20), gan_nhat(a, 100), gan_nhat(a, 1))

PYTHON 6A · 4

Nhị phân trên đáp án

Ý tưởng “mở rộng”

Không tìm trong mảng mà tìm trong miền đáp án khi bài toán có tính đơn điệu: nếu x thoả thì mọi x lớn hơn cũng thoả (hoặc ngược lại).

Hàm kiểm tra(x) trả đúng/sai; nhị phân tìm x nhỏ nhất thoả.

Ví dụ: tìm căn bậc hai nguyên; chia dây cho k người; số ngày xong việc…

def isqrt(n):
    l, r = 0, n
    while l < r:
        m = (l + r + 1) // 2
        if m * m <= n:
            l = m
        else:
            r = m - 1
    return l
print(isqrt(99), isqrt(100), isqrt(10**18))
Kết quả
9 10 1000000000
Dạng l = m cần m = (l + r + 1) // 2 (lệch lên) để tránh lặp vô hạn.

Bài toán: cắt dây

Đề bài

Có n sợi dây dài a[i]. Cần cắt ra ít nhất k đoạn bằng nhau (mỗi đoạn dài nguyên L). Tìm L lớn nhất.

Kiểm tra(L): tổng a[i] // L ≥ k? L càng nhỏ càng dễ thoả → đơn điệu.

Nhị phân L từ 1 đến max(a): O(n log max).

def cat(a, k):
    l, r = 0, max(a)
    while l < r:
        m = (l + r + 1) // 2
        if sum(x // m for x in a) >= k:
            l = m
        else:
            r = m - 1
    return l
print(cat([802, 743, 457, 539], 11))
print(cat([5, 5], 20))
Kết quả
200
0
Dây dài 802, 743, 457, 539 cắt đoạn 200: 4 + 3 + 2 + 2 = 11 đoạn → L = 200.
PYTHON 6A · 4

Các lỗi phổ biến của nhị phân

Bốn lỗi kinh điển

  • l = m hoặc r = m (thiếu ±1) → lặp vô hạn.
  • Điều kiện lặp l < r thay vì l ≤ r → bỏ sót.
  • Dãy chưa sắp xếp.
  • Với chặn dưới/trên: sai lệch khi tìm đầu tiên/cuối cùng.
Khi thi, tự thử với dãy 1 phần tử, 2 phần tử, k nhỏ nhất, k lớn nhất, k không có.
def tim_sai(a, k):
    l, r = 0, len(a) - 1
    while l <= r:
        m = (l + r) // 2
        if a[m] == k:
            return m
        elif a[m] < k:
            l = m + 1
        else:
            r = m
    return -1
print(tim_sai([1, 3, 5], 5))
print(tim_sai([1, 3, 5], 0))
Không chạy thử vì treo
Với k = 0 (nhỏ hơn mọi phần tử): chương trình lặp vô hạn vì r = m không thu hẹp khi l = r = 0.

Tự kiểm tra: số lần so sánh

Câu hỏi

Mảng tăng 15 phần tử như trên. Tìm 95, 23, 56, 100 cần bao nhiêu lần so sánh?

a = [2, 5, 8, 12, 16, 23, 38, 56, 72, 91, 95, 99, 104, 110, 120]
# dùng hàm tim ở trên
print([tim(a, k)[1] for k in (95, 23, 56, 100)])

Đáp án và giải thích từng bước

Dãy có 15 phần tử, m đầu = 7 (giá trị 56).

56: bằng ngay → 1 lần.

23: 23 < 56 → trái [0..6], m = 3 (12) < 23 → [4..6], m = 5 = 23: 3 lần.

95: phải [8..14], m = 11 (99) > 95 → [8..10], m = 9 (91) < 95 → [10..10], m = 10: 4 lần.

100: không có, tới khi l > r: 4 lần. Đáp án 4 3 1 4.

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • Tuần tự: duyệt từng phần tử, O(n), không cần sắp xếp.
  • Nhị phân: dãy đã sắp xếp, loại một nửa mỗi lần, O(log n).
  • Cập nhật l = m + 1, r = m − 1; điều kiện l ≤ r.
  • Số lần so sánh tối đa: ⌊log₂ n⌋ + 1.
  • Vị trí đầu/cuối: ghi nhận kết quả rồi tìm tiếp một phía; bisect_left/right.
  • Nhị phân trên đáp án khi điều kiện đơn điệu.

NÂNG CAO

Điều dễ nhầm và mở rộng

Bẫy thường gặp

  • Tìm 1 lần: tuần tự rẻ hơn sắp xếp + nhị phân.
  • l = m cần m = (l + r + 1) // 2.
  • a.index báo lỗi nếu không có.
  • Nhị phân trên đáp án: xác định đơn điệu trước.

Mở rộng

  • Tìm kiếm tam phân cho hàm lồi.
  • Nhị phân trên số thực.
  • Fractional cascading.
