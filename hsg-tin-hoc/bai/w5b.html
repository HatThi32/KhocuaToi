Flexbox: bật bố cục linh hoạt

display: flex

Đặt display: flex cho phần tử cha (flex container); các con trực tiếp thành flex item xếp theo hàng ngang.

Hai trục: trục chính (main axis, mặc định ngang) và trục phụ (cross axis, vuông góc).

.f { display: flex; }
trang-mau.html
Không có flex: ba hộp xếp dọc (block). Có display:flex: xếp ngang.

CSS 5B · 1

flex-direction và flex-wrap

Đổi hướng trục chính

row (mặc định): trục chính ngang. column: trục chính dọc.

Khi column, hai trục đổi vai: justify-content căn dọc, align-items căn ngang.

flex-wrap: wrap: cho xuống dòng khi hết chỗ; gap: khoảng cách giữa các item.

Với flex-direction: column, trục chính trở thành chiều dọc.

CSS 5B · 2

absolute: mốc là tổ tiên đã định vị

Ví dụ góc hộp

Cha có position: relative; con absolute với top, right bám góc trên phải của cha.

Nếu cha không định vị, con lấy mốc xa hơn (thường là trang).

.cha { position: relative; }
.con { position: absolute;
       top: 0; right: 0; }

CSS 5B · 2

fixed và sticky

Hai kiểu “dính”

fixed: mốc là khung nhìn; ra khỏi luồng; đứng yên khi cuộn (thanh menu, nút lên đầu trang).

sticky: bình thường như relative, tới ngưỡng (top:0) thì dính lại.

.menu {
  position: fixed;
  top: 0; left: 0; width: 100%;
}
th { position: sticky; top: 0; }
Muốn thanh luôn ở đầu màn hình khi cuộn: position: fixed.
CSS 5B · 3

Đơn vị tương đối cho giao diện co giãn

em, rem, %, vw

em: theo cỡ chữ của phần tử (hoặc cha khi dùng cho font-size).

rem: theo cỡ chữ gốc (html) → ổn định hơn em.

%: theo kích thước phần tử cha. vw/vh: % bề rộng/cao khung nhìn.

Đơn vịCơ sở tính
pxcố định
emcỡ chữ phần tử
remcỡ chữ của html
%phần tử cha
vw1% bề rộng cửa sổ
Cỡ chữ html 16px: 2rem = 32px; chữ 20px: 1.5em = 30px.
CSS 5B · 4

@media: giao diện đáp ứng

Quy tắc theo cỡ màn hình

@media (max-width: 600px) { … }: các quy tắc bên trong chỉ áp dụng khi bề rộng khung nhìn ≤ 600px (điện thoại).

Cần thẻ: <meta name="viewport" content="width=device-width, initial-scale=1">.

.f { display: flex; }
@media (max-width: 600px) {
  .f { flex-direction: column; }
}
@media (max-width: 600px) có tác dụng khi màn hình hẹp từ 600px trở xuống.

Tự kiểm tra: trục chính

Câu hỏi

Trong Flexbox, thuộc tính nào căn theo trục chính? Thuộc tính nào căn theo trục phụ? Khi flex-direction: column thì sao?

.f { display:flex;
     justify-content:center;
     align-items:center; }

Đáp án và giải thích từng bước

Trục chính: justify-content; trục phụ: align-items.

Khi column, hai trục đổi vai: justify-content căn dọc, align-items căn ngang.

Tự kiểm tra (HSG): đúng hay sai?

Câu hỏi

(a) fixed lấy khung nhìn làm mốc. (b) display:none vẫn chiếm chỗ. (c) @media (max-width:600px) áp dụng khi màn ≤ 600px. (d) rem tính theo cỡ chữ của html. (e) sticky ra khỏi luồng như absolute.

Đáp án và giải thích từng bước

(a) Đúng.

(b) Sai: none loại hẳn khỏi bố cục.

(c) Đúng.

(d) Đúng.

(e) Sai: sticky vẫn nằm trong luồng.

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • display:flex trên cha; justify-content = trục chính; align-items = trục phụ.
  • flex-direction: column đổi vai hai trục.
  • position: relative (lệch tại chỗ), absolute (theo tổ tiên định vị), fixed (theo khung nhìn), sticky.
  • Đơn vị: px, em, rem, %, vw.
  • @media (max-width: …) cho giao diện đáp ứng.
