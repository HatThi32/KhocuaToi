AI 3 · 3

Rò rỉ dữ liệu

Thông tin kiểm tra lọt vào huấn luyện

Chuẩn hoá cả tập (trung bình, độ lệch chuẩn tính trên cả huấn luyện lẫn kiểm tra) rồi mới chia → rò rỉ: kết quả lạc quan.

Dùng tập kiểm tra để chỉnh tham số → đánh giá không khách quan.

Cách đúng: chia trước; tham số chuẩn hoá tính chỉ trên tập huấn luyện, rồi áp sang tập kiểm tra.

Quy tắc: chia tập trước, xử lí sau.

AI 3 · 4

Bài mẫu: TP=40, FP=10, FN=20, TN=30

Ý chính

Accuracy = 70/100 = 70%; precision = 40/50 = 80%.

Recall = 40/60 ≈ 66,7% (không phải 80%).

20 thư rác bị bỏ sót (FN).

TP,FP,FN,TN=40,10,20,30
n=TP+FP+FN+TN
P=TP/(TP+FP); R=TP/(TP+FN)
print('accuracy',(TP+TN)/n)
print('precision',P)
print('recall',round(R,3))
print('F1',round(2*P*R/(P+R),3))
print('bỏ sót',FN)
Kết quả chạy Python thật
accuracy 0.7
precision 0.8
recall 0.667
F1 0.727
bỏ sót 20
Đừng nhầm precision với recall.

Bẫy: 95% âm tính, mô hình luôn đoán “âm”

Ý chính

Accuracy = 95% nhưng recall = 0: bỏ sót mọi ca dương.

Dữ liệu mất cân bằng → cần xét precision, recall, F1.

n=100; pos=5
TP=0; FN=pos; TN=n-pos; FP=0
print('accuracy',(TP+TN)/n)
print('recall',TP/(TP+FN))
print('precision','không xác định (không báo dương nào)')

recall 0.0

Đáp án: accuracy 95% nhưng recall lớp dương = 0.

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • 3 tập: huấn luyện / kiểm định / kiểm tra.
  • Huấn luyện cao, kiểm tra thấp = quá khớp.
  • Chia trước, chuẩn hoá chỉ trên huấn luyện (tránh rò rỉ).
  • Precision = TP/(TP+FP); recall = TP/(TP+FN); accuracy = (TP+TN)/n.
  • Dữ liệu mất cân bằng: accuracy đánh lừa.
