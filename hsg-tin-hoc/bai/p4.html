    if n < 2:
        return False

Hàm gọi hàm và docstring

def uoc_chung(a, b):
    """Trả về ƯCLN của a và b."""
    while b:
        a, b = b, a % b
    return a

def boi_chung(a, b):
    return a * b // uoc_chung(a, b)

print(uoc_chung(48, 18), boi_chung(4, 6))
Docstring (chuỗi ba nháy đầu thân hàm) mô tả công dụng. BCNN = a·b / ƯCLN.

try – except – else – finally

def chia(a, b):
    try:
        r = a / b
    except ZeroDivisionError:
        return "lỗi chia 0"
    else:
        return r
    finally:
        print("đã xử lí xong")

print(chia(1, 0))
else: chạy khi không có lỗi. finally: luôn chạy, dù có lỗi hay không.

Quy trình gỡ lỗi

Các bước

  • Đọc thông báo lỗi, xác định dòng.
  • Tái hiện lỗi với dữ liệu nhỏ.
  • In giá trị biến trung gian hoặc trace bảng.
  • Sửa từng lỗi một rồi chạy lại.
  • Thêm ca kiểm thử để lỗi không quay lại.
Gỡ lỗi (debug) là kĩ năng của lập trình viên: giả thuyết → kiểm chứng → sửa.

IDLE có chế độ Debugger chạy từng dòng; trên máy có thể dùng print để theo dõi.

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • def + return; không return → None; print ≠ return.
  • Tham số mặc định đặt sau; có thể gọi theo tên; trả về tuple.
  • Biến cục bộ trong hàm; sửa toàn cục cần global.
  • Lỗi: cú pháp, runtime (ngoại lệ), logic.
  • try/except/else/finally; assert để kiểm thử.
Cần…Dùng
Trả kết quảreturn
Bắt lỗitry / except
Kiểm thửassert
Báo lỗiraise
Quên return; thụt lề sai; biến cục bộ không tồn tại ngoài hàm.
NÂNG CAO

Điều dễ nhầm và mở rộng

Bẫy thường gặp

  • def f(a=[]): a.append(1): đối số mặc định list dùng chung giữa các lần gọi (bẫy).
  • except: trần che giấu lỗi; nên nêu tên ngoại lệ.
  • finally chạy kể cả khi có return trong try.
  • Hàm gọi chính nó là đệ quy (Python 7).

Mở rộng

  • Hàm lambda: f = lambda x: x*x.
  • Đối số tuỳ ý: *args, **kwargs.
  • Mô-đun unittest cho kiểm thử chuyên nghiệp.
