Câu hỏi mở đầu

Một tệp CSS cho cả website?

  • Có thể: mọi trang cùng link tới một tệp CSS ngoài.
  • Mỗi trang có tệp HTML riêng.
  • Sửa một chỗ trong CSS: cả website đổi theo.
Các bước: (1) tạo thư mục site; (2) viết style.css; (3) mỗi trang HTML có <link href="style.css" rel="stylesheet">.

Đây là cách CSS ngoài học ở Bài 13 phát huy tác dụng.

Lớp .banner: ảnh nền và tiêu đề

.banner {
  background: url("../assets/img/bg.jpg")
     no-repeat center center;
  background-size: cover;
  padding-top: 12rem;
  padding-bottom: 12rem;
  color: white;
  text-align: center;
}
padding-top, padding-bottom làm banner cao; rem là đơn vị tương đối so với cỡ chữ của phần tử gốc.

Chia cột trong một hàng

Vì sao cần chia cột

  • Nhiều ô cùng một hàng tạo sự cân đối, hài hoà.
  • Dùng cho slogan (3 ô) và nội dung (2 ô mỗi hàng).
  • Cách làm: lớp .row + display: flex.
.row {
  display: flex;
  flex-wrap: wrap;
  max-width: 100%;
  padding: 0 3rem;
}

Vận dụng: thiết kế mới

Việc cần làm

  • Đưa ra một thiết kế khác cho website.
  • Chỉ viết lại tệp CSS theo thiết kế mới.
  • Không sửa các tệp HTML (hoặc sửa rất ít).
Đây chính là sức mạnh của CSS: tách nội dung (HTML) và hình thức (CSS). Đổi một tệp, cả website thay đổi.

Gợi ý: đổi bảng màu, đổi font, đổi từ 3 cột sang 2 cột (block_3 → block_2).

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • Một tệp CSS ngoài dùng chung cho nhiều trang.
  • Bố cục: header/banner, slogan, content, footer; mỗi phần một lớp.
  • display: flex + flex-wrap + width % để chia cột trong một hàng.
  • Liên kết các trang bằng đường dẫn tương đối.
  • Đổi giao diện: chỉ cần sửa tệp CSS.

NÂNG CAO

Mở rộng

Kĩ thuật hay gặp

  • Responsive: dùng @media để 3 cột xếp thành 1 cột trên điện thoại.
  • Grid: display: grid; grid-template-columns: 1fr 1fr 1fr;.
  • Biến CSS: :root {--mau: #D84315;} rồi color: var(--mau);.
