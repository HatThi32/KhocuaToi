Phát hiện phần tử trùng: list chậm, set nhanh

So sánh hai cách

Dùng list seen: mỗi lần x in seen duyệt cả list → tổng O(n²).

Dùng set: kiểm tra và thêm đều O(1) trung bình → tổng O(n).

Cách ngắn nhất: len(set(a)) != len(a).

def co_trung(a):
    seen = set()
    for x in a:
        if x in seen:
            return True
        seen.add(x)
    return False
print(co_trung([3, 1, 4, 1]), co_trung([1, 2, 3]))
print(len(set([3, 1, 4, 1])) != 4)

Tự kiểm tra: sao chép

Câu hỏi

Cho a = [5, 3, 8, 1]; b = a; b.append(7); c = a[:]; c.sort(). In a, c.

a = [5, 3, 8, 1]

c.sort()

b là tên khác của a → b.append(7) làm a = [5, 3, 8, 1, 7].

c là bản sao (chụp sau khi a đã có 7) → [5, 3, 8, 1, 7]; sort → [1, 3, 5, 7, 8] và a không đổi.

Tự kiểm tra (HSG): phát biểu đúng/sai

Câu hỏi

Cho: a = [4, 8, 15, 16, 23, 42]; d = list(zip(a, a[1:])). Có đúng “d có 6 cặp” không? Tập {x % 5 for x in a} có mấy phần tử?

a = [4, 8, 15, 16, 23, 42]
d = list(zip(a, a[1:]))
print(len(d), len({x % 5 for x in a}))

Đáp án và giải thích từng bước

zip dừng ở dãy ngắn nhất: a có 6, a[1:] có 5 → d có 5 cặp. Phát biểu “6 cặp” là sai.

Dư khi chia 5: 4, 3, 0, 1, 3, 2 → tập {0, 1, 2, 3, 4} có 5 phần tử (3 trùng được loại).

Tự kiểm tra (HSG): ngăn xếp bằng list

Câu hỏi

Chương trình sau in ra gì? Giải thích bằng bảng theo dõi ngăn xếp st.

st = []
kq = []
for ch in "abcdef":
    st.append(ch)
    if len(st) == 3:
        kq.append(st.pop())
        kq.append(st.pop())
print(kq, st)

Đáp án và giải thích từng bước

Thêm a, b → st = [a, b]; thêm c → st = [a, b, c], đủ 3: pop c, pop b → kq = [c, b], st = [a].

Thêm d → [a, d]; thêm e → [a, d, e], đủ 3: pop e, pop d → kq = [c, b, e, d], st = [a].

Thêm f → [a, f] (2 phần tử, chưa đủ 3). Kết quả: kq = [c, b, e, d], st = [a, f].

Kết quả thật
['c', 'b', 'e', 'd'] ['a', 'f']
TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • List: mutable, có chỉ số, cắt lát như xâu; tuple bất biến; set không trùng; dict khoá → giá trị.
  • b = a là hai tên một danh sách; a[:] là bản sao nông; lồng nhau cần sao chép sâu.
  • sort() sửa tại chỗ, trả None; sorted() trả danh sách mới; key chọn tiêu chí.
  • Comprehension, zip (dừng ở dãy ngắn), enumerate.
  • in trên set/dict nhanh O(1), trên list chậm O(n).
  • Hàm sửa trực tiếp danh sách tham số làm đổi danh sách gốc.
Cần…Dùng
Bản sao nônga[:], a.copy()
Sắp xếp mớisorted(a)
Tập rỗngset()
Cặp kềzip(a, a[1:])

NÂNG CAO

Điều dễ nhầm và mở rộng

Bẫy thường gặp

  • (5) không phải tuple; phải (5,).
  • {} là dict rỗng, không phải set.
  • [[0]*3]*3 tạo các hàng trùng nhau.
  • Khoá dict phải bất biến.

Mở rộng

  • collections: Counter, deque, defaultdict.
  • heapq (hàng đợi ưu tiên).
  • bisect tìm kiếm nhị phân trên list.
