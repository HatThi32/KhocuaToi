Chia nguyên và chia dư: nhìn như phép chia ở tiểu học

17 chia 5

Chia 17 kẹo cho 5 bạn: mỗi bạn được 3 cái, còn dư 2 cái.

17 // 5 = 3 (thương) và 17 % 5 = 2 (số dư).

Hai kết quả liên hệ bằng đẳng thức luôn đúng:

a = (a // b) × b + a % b

Kiểm tra: 3 × 5 + 2 = 17 ✓.

print(17 // 5, 17 % 5)
print(20 // 5, 20 % 5)
print(3 // 5, 3 % 5)
print(17 / 5)

% với số âm: dư luôn cùng dấu với số chia

Cách tính an toàn

Dùng đẳng thức: a % b = a − (a // b) × b.

Ví dụ -7 % 2: -7 // 2 = -4, nên -7 % 2 = -7 − (−4)×2 = -7 + 8 = 1.

Quy tắc rút gọn: kết quả % luôn nằm từ 0 đến b−1 khi b dương (và cùng dấu với b khi b âm).

print(-7 // 2, -7 % 2)
print(7 // -2, 7 % -2)
print(-7 // -2, -7 % -2)
print(-7 % 3, -8 % 3, -9 % 3)

** kết hợp từ PHẢI sang TRÁI

Đề thi hay hỏi

Các phép + − × / // % cùng mức ưu tiên thì tính trái sang phải.

Riêng ** tính phải sang trái:

2 ** 3 ** 2 = 2 ** (3 ** 2) = 2 ** 9 = 512
chứ không phải (2 ** 3) ** 2 = 64.

Dấu trừ đứng trước: -3 ** 2 = -(3 ** 2) = -9, còn (-3) ** 2 = 9.

print(2 ** 3 ** 2)
print((2 ** 3) ** 2)
print(-3 ** 2)
print((-3) ** 2)
print(10 - 2 - 3)
print(100 / 10 / 2)

Điều khác với toán học phổ thông

Đoản mạch: and, or trả về chính toán hạng

Hai quy tắc

A or B: nếu A đúng (“thật”) thì trả về A và bỏ qua B; ngược lại trả về B.

A and B: nếu A sai (“giả”) thì trả về A và bỏ qua B; ngược lại trả về B.

Giá trị “giả”: 0, 0.0, "" , danh sách rỗng, False.

Phép toán trên bit (nâng cao)

Làm việc với dãy 0 và 1

  • a & b (và): bit nào cả hai là 1 thì ra 1.
  • a | b (hoặc): ra 1 nếu ít nhất một là 1.
  • a ^ b (xor): ra 1 nếu hai bit khác nhau.
  • a >> k: dịch phải k bit = a // 2k.
  • a << k: dịch trái k bit = a × 2k.

print(37 >> 2, 37 << 1)

Bài mẫu: đổi số giây ra giờ – phút – giây

Phân tích

  1. Đầu vào: số giây s (ví dụ 3725).
  2. Giờ = s // 3600; còn lại s % 3600 giây.

Kiểm tra: 3725 = 1×3600 + 2×60 + 5.

phut = s % 3600 // 60
giay = s % 60

print(divmod(s, 3600))

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • // làm tròn xuống (−7 // 2 = −4); a = (a // b)·b + a % b.
  • %: dư; dương khi chia cho số dương: −7 % 3 = 2.
  • ** kết hợp phải sang trái: 2 ** 3 ** 2 = 512; −3 ** 2 = −9.
  • Ưu tiên: ( ) › ** › × / // % › + − › so sánh › not › and › or.
  • round làm tròn chẵn ở giữa: round(2.5) = 2.
  • and/or đoản mạch, trả về toán hạng quyết định.

NÂNG CAO

Điều dễ nhầm và mở rộng

Bẫy thường gặp

  • n % 2 == 1 đúng với số lẻ dương và âm trong Python (−3 % 2 = 1).
  • x == 3 or 5 luôn đúng.
  • n & 1 kiểm tra chẵn lẻ nhanh; n >> 1 = n // 2.
  • 0.1 + 0.2 != 0.3.

Mở rộng

  • Số dư toán học luôn không âm (vì sao Python chọn vậy).
  • Số tuần hoàn trong biểu diễn số thực.
  • Dịch bit và nhân/chia nhanh cho luỹ thừa của 2.
