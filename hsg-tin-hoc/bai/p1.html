TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • print: sep, end; = là phép gán; tên biến không bắt đầu bằng số.
  • / → float; // chia nguyên; % dư; ** phải sang trái.
  • Ưu tiên logic: not › and › or; so sánh cho bool.
  • input() luôn trả về str: phải ép kiểu int(), float().
  • int(3.9)=3 (cắt phần thập phân), "ab"*3="ababab".
Cần…Dùng
Đếm chữ số cuốin % 10
Bỏ chữ số cuốin // 10
Chẵn / lẻn % 2 == 0
Hoán đổia, b = b, a
Không cộng được xâu với số; = khác ==.
NÂNG CAO

Điều dễ nhầm và mở rộng

Bẫy thường gặp

  • -7 // 2 = -4 (về phía âm vô cùng), không phải -3.
  • 2**3**2 = 512, -3**2 = -9.
  • True + True = 2 (bool là số); "a" < "B" là False (mã chữ hoa nhỏ hơn).
  • round(2.5) = 2, round(3.5) = 4 (làm tròn về chẵn).

Mở rộng

  • Phân tích biểu thức: đọc từ ngoài vào trong, tính theo ưu tiên.
  • divmod(a,b) trả cặp (thương, dư).
  • f-string hỗ trợ biểu thức ngay trong {}.
