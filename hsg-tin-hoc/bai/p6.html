Tìm kiếm tuần tự

def tim(a, x):
    for i in range(len(a)):
        if a[i] == x:
            return i
    return -1

a = [5, 8, 2, 9, 4]
print(tim(a, 9))
print(tim(a, 7))
Duyệt từ đầu, gặp x thì trả về chỉ số; hết dãy không thấy thì trả về -1. Độ phức tạp O(n); dùng được cho dãy bất kì.

Tìm kiếm nhị phân: ý tưởng

Điều kiện và ý tưởng

  • Dãy phải đã sắp xếp tăng.
  • So sánh x với phần tử giữa a[m].
  • Nếu bằng: tìm thấy.
  • Nếu x lớn hơn: tìm tiếp nửa phải; nhỏ hơn: nửa trái.
  • Mỗi lần loại một nửa → O(log n).

Cài đặt tìm kiếm nhị phân

def nhi_phan(a, x):
    l, r = 0, len(a) - 1
    while l <= r:
        m = (l + r) // 2
        if a[m] == x:
            return m
        if a[m] < x:
            l = m + 1
        else:
            r = m - 1
    return -1

a = [2, 5, 8, 11, 15, 20, 27]
print(nhi_phan(a, 20))
print(nhi_phan(a, 7))
Điều kiện lặp l <= r; sau mỗi lần xét l = m + 1 hoặc r = m - 1 (loại cả a[m]).

Sắp xếp chọn (selection sort): ý tưởng

Ý tưởng

  • Lượt i: tìm phần tử nhỏ nhất trong đoạn a[i..n-1].
  • Đổi chỗ nó với a[i].
  • Sau lượt i, a[0..i] đã đúng vị trí cuối cùng.
  • Lặp n-1 lượt.
Số phép so sánh: (n-1) + (n-2) + … + 1 = n(n-1)/2 → O(n²). Số lần đổi chỗ chỉ tối đa n-1.

Ưu điểm: ít đổi chỗ; nhược: luôn tốn O(n²) so sánh, kể cả dãy đã sắp.

PYTHON 6 · 2

Cài đặt sắp xếp chọn

def chon(a):
    n = len(a)
    for i in range(n - 1):
        k = i
        for j in range(i + 1, n):
            if a[j] < a[k]:
                k = j
        a[i], a[k] = a[k], a[i]

a = [64, 25, 12, 22, 11]
chon(a)
print(a)
k lưu vị trí phần tử nhỏ nhất; cuối lượt đổi chỗ a[i], a[k] = a[k], a[i].

Sắp xếp nổi bọt (bubble sort): ý tưởng

Ý tưởng

  • So sánh hai phần tử kề nhau; nếu sai thứ tự thì đổi chỗ.
  • Sau mỗi lượt, phần tử lớn nhất “nổi” về cuối.
  • Lặp tới khi một lượt không đổi chỗ lần nào.
Độ phức tạp O(n²); với dãy đã sắp và có cờ dừng sớm chỉ O(n).
Nổi bọt đổi chỗ nhiều nhất trong ba thuật toán.
PYTHON 6 · 3

Cài đặt sắp xếp nổi bọt

def noi_bot(a):
    n = len(a)
    for i in range(n - 1):
        doi = False
        for j in range(n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                doi = True
        if not doi:
            break

a = [5, 1, 4, 2, 8]
noi_bot(a)
print(a)
Biến cờ doi giúp dừng sớm khi dãy đã sắp. Vòng trong chạy n-1-i lần vì i phần tử cuối đã đúng chỗ.

Sắp xếp chèn (insertion sort): ý tưởng

Giống xếp bài trên tay

  • Giả sử a[0..i-1] đã sắp.
  • Lấy a[i] làm “lá bài mới”.
  • Dịch sang phải các phần tử lớn hơn.
  • Chèn vào vị trí thích hợp.
O(n²) nhưng rất nhanh với dãy gần như đã sắp (O(n)). Thực tế hay được dùng cho mảng nhỏ.
PYTHON 6 · 3

Cài đặt sắp xếp chèn

def chen(a):
    for i in range(1, len(a)):
        x = a[i]
        j = i - 1
        while j >= 0 and a[j] > x:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = x

a = [7, 3, 9, 1, 5]
chen(a)
print(a)
Vòng while dịch các phần tử > x sang phải; a[j+1] = x đặt x vào chỗ trống.
Thứ tự điều kiện j >= 0 and a[j] > x quan trọng để không bị IndexError.

Đếm số phép so sánh

def dem(thuat_toan, a):
    a = a[:]
    n = len(a)
    so = 0
    if thuat_toan == "chon":
        for i in range(n - 1):
            k = i
            for j in range(i + 1, n):
                so += 1
                if a[j] < a[k]:
                    k = j
            a[i], a[k] = a[k], a[i]
    return so

for n in [10, 100, 1000]:
    print(n, dem("chon", list(range(n, 0, -1))))
Chọn: đúng n(n-1)/2 phép so sánh: 45; 4 950; 499 500 — tăng 100 lần khi n tăng 10 lần.

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • Tuần tự: O(n), dãy bất kì. Nhị phân: O(log n), dãy đã sắp.
  • Nhị phân: l ≤ r, m = (l+r)//2, loại nửa theo so sánh.
  • Chọn: chọn min rồi đổi chỗ. Nổi bọt: đổi cặp kề. Chèn: chèn vào đoạn đã sắp.
  • Cả ba đều O(n²); thực tế dùng sort() O(n log n).
  • Trace từng lượt là kĩ năng chính của đề thi.

NÂNG CAO

Điều dễ nhầm và mở rộng

Bẫy thường gặp

  • m = (l + r) // 2 luôn đúng với số nguyên Python (không tràn số).
  • Sắp chọn không ổn định: có thể đảo thứ tự hai phần tử bằng nhau.
  • Nổi bọt và chèn ổn định.
  • Tìm nhị phân dùng bisect.

Mở rộng

  • Sắp xếp trộn (merge sort) và nhanh (quick sort): O(n log n) (chia để trị, Python 7).
  • Sắp xếp đếm O(n + k) khi giá trị nhỏ.
  • Tìm nhị phân trên đáp số (bài toán “tìm kết quả nhỏ nhất thoả điều kiện”).
