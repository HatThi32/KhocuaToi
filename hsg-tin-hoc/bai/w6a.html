WEB 6A · 1

Quy trình xây dựng website

Các bước

  1. Xác định mục tiêu, đối tượng người dùng, nội dung.
  2. Thiết kế: sơ đồ trang, bố cục, màu sắc, phông chữ.
  3. Xây dựng: viết HTML, CSS (và JavaScript).
  4. Kiểm thử: lỗi, liên kết, hiển thị trên nhiều thiết bị.
  5. Xuất bản: đưa lên máy chủ web, có địa chỉ truy cập.
  6. Bảo trì: cập nhật nội dung, sửa lỗi.
Thứ tự: phân tích → thiết kế → xây dựng → kiểm thử → xuất bản → bảo trì.
WEB 6A · 1

Sơ đồ website và tổ chức thư mục

Cấu trúc gọn gàng

Lập sơ đồ trang: trang chủ liên kết tới các trang con.

Gom tệp theo loại: css/, anh/, js/; trang index.html là trang chủ.

Dùng đường dẫn tương đối để chuyển thư mục không hỏng liên kết.

website/
├── index.html
├── gioithieu.html
├── lienhe.html
├── css/
│   └── style.css
└── anh/
    └── logo.png
Từ gioithieu.html nối CSS: href="css/style.css".
WEB 6A · 2

Một tệp CSS dùng chung

Vì sao nên dùng chung?

Mọi trang cùng nối một tệp style.css bằng thẻ link trong head.

Sửa một nơi, đổi cả website: màu, phông, bố cục thống nhất.

Dễ bảo trì hơn viết CSS riêng trong từng trang.

<!-- trong head của mọi trang -->
<link rel="stylesheet"
      href="css/style.css">
Muốn giao diện giống nhau nhiều trang: một tệp CSS ngoài + thẻ link.
WEB 6A · 2

Bố cục trang phổ biến

Dùng thẻ ngữ nghĩa

header (đầu trang, logo), nav (menu), main (nội dung), aside (thanh bên), footer (chân trang).

Dùng Flexbox để chia cột; @media để đáp ứng điện thoại.

WEB 6A · 3

Kiểm thử website

Cần kiểm tra gì?

  • Liên kết: không có liên kết hỏng (404).
  • Hiển thị trên nhiều trình duyệt (Chrome, Firefox, Edge…).
  • Thiết bị: máy tính, máy tính bảng, điện thoại.
  • Chính tả, ảnh tải được, alt đầy đủ.
  • Tốc độ tải và dung lượng ảnh.
Công cụ F12 (DevTools) của trình duyệt giúp xem phần tử, CSS áp dụng, lỗi và mô phỏng điện thoại.
WEB 6A · 4

Xuất bản website

Đưa lên Internet

Cần tên miền và dịch vụ lưu trữ (hosting): thuê máy chủ hoặc dùng dịch vụ miễn phí.

Tải tệp của website lên máy chủ; người dùng truy cập bằng URL.

Kiểm tra lại sau khi xuất bản: địa chỉ đúng, liên kết, ảnh.

CáchVí dụ
viết mã thủ côngHTML, CSS, JS
công cụ tạo trang trực tuyếnGoogle Sites, Wix
hệ quản trị nội dung (CMS)WordPress
lưu trữ miễn phíGitHub Pages
Không cần viết mã: dùng công cụ tạo trang như Google Sites, kéo thả và xuất bản trực tuyến.
WEB 6A · 5

Tự kiểm tra: sắp xếp bước

Câu hỏi

Sắp xếp theo thứ tự: (1) xuất bản; (2) xác định mục tiêu; (3) kiểm thử; (4) xây dựng bằng HTML, CSS; (5) thiết kế bố cục.

Đáp án và giải thích từng bước

Đúng thứ tự: (2) → (5) → (4) → (3) → (1): mục tiêu → thiết kế → xây dựng → kiểm thử → xuất bản.

WEB 6A · 5

Tự kiểm tra (HSG): đúng hay sai?

Câu hỏi

(a) Nhiều trang nối chung một tệp CSS ngoài. (b) Thẻ link đặt trong body. (c) Cần kiểm thử trên nhiều trình duyệt. (d) Google Sites cần viết mã HTML. (e) Dùng đường dẫn tương đối giúp chuyển thư mục không hỏng.

Đáp án và giải thích từng bước

(a) Đúng.

(b) Sai: link đặt trong head.

(c) Đúng.

(d) Sai: kéo thả, không cần viết mã.

(e) Đúng.

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • Quy trình: mục tiêu → thiết kế → xây dựng → kiểm thử → xuất bản → bảo trì.
  • Tổ chức thư mục: css/, anh/, index.html; dùng đường dẫn tương đối.
  • Một CSS chung nối bằng link trong head.
  • Kiểm thử: liên kết, trình duyệt, thiết bị.
  • Xuất bản: hosting + tên miền; hoặc Google Sites.

NÂNG CAO

Điều dễ nhầm và mở rộng

Bẫy thường gặp

  • Favicon biểu tượng tab.
  • SEO cơ bản: title, mô tả.
  • Sao lưu trước khi cập nhật.

Mở rộng

  • Git và GitHub Pages.
  • HTTPS bắt buộc cho trang đăng nhập.
  • Hiệu năng: nén ảnh.
