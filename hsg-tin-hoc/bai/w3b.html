CSS 3B · 3

Lớp giả (pseudo-class)

Trạng thái của phần tử, viết sau MỘT dấu :

a:link chưa thăm; a:visited đã thăm; a:hover khi trỏ chuột lên; a:active khi đang nhấn.

:focus ô đang nhập.

:first-child, :nth-child(n): theo vị trí.

Thứ tự nên viết: link → visited → hover → active.

a:hover   { color: red; }
a:visited { color: purple; }
li:first-child { font-weight: bold; }
trang-mau.html
Hover: a:hover; đã thăm: a:visited. Lớp giả dùng 1 dấu hai chấm.
CSS 3B · 3

Phần tử giả (pseudo-element)

Một phần nội dung, viết sau HAI dấu ::

::first-line: dòng đầu của đoạn.

::first-letter: kí tự đầu.

::before / ::after: chèn nội dung bằng thuộc tính content.

::selection: phần chữ đang bôi chọn.

p::first-line   { color: red; }
p::first-letter { font-size: 2em; }
h2::before { content: "★ "; }
trang-mau.html
::first-line chỉ tô dòng đầu tiên của đoạn.

Tự kiểm tra: đếm phần tử

Câu hỏi

Trên trang mẫu, bộ chọn div p và div > p chọn được bao nhiêu phần tử p? Có khác nhau không?

<div id="menu" class="box">
 <h2>Tin tức</h2>
 <p class="note">Ghi chú 1</p>
 <p>Đoạn 2 <em>nhấn</em></p>
 <ul>
  <li><a href="a.html">A</a></li>
  <li class="note"><a href="b.html">B</a></li>
 </ul>
</div>
<p>Đoạn ngoài</p>

Đáp án và giải thích từng bước

Cả hai: 2 phần tử p (hai p nằm trực tiếp trong div).

Khác nhau chỉ khi p nằm sâu hơn (vd. trong ul): khi đó div p chọn, div > p không.

p “Đoạn ngoài” không nằm trong div nên không được chọn.

CSS 3B · 4

Tự kiểm tra (HSG): đúng hay sai?

Câu hỏi

(a) p::first-line chọn dòng đầu của đoạn. (b) .note chỉ chọn được thẻ p. (c) #menu nên dùng cho nhiều phần tử. (d) h2 + p chọn mọi p sau h2. (e) a[href] chọn thẻ a có thuộc tính href.

Đáp án và giải thích từng bước

(a) Đúng.

(b) Sai: class dùng cho mọi thẻ.

(c) Sai: id duy nhất; nhiều phần tử dùng class.

(d) Sai: + chỉ p ngay sau; ~ mới là mọi p sau.

(e) Đúng.

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • p thẻ; .c lớp; #i id; [a] thuộc tính.
  • cách = hậu duệ; > = con trực tiếp; + = kề sau; ~ = mọi anh em sau; , = nhóm.
  • Lớp giả : (hover, visited, nth-child); phần tử giả :: (first-line, first-letter, before).
  • Đếm phần tử: vẽ cây rồi áp từng bộ chọn.

NÂNG CAO

Điều dễ nhầm và mở rộng

Bẫy thường gặp

  • :not(.x) loại trừ.
  • :last-child, :nth-child(odd).
  • * chọn mọi phần tử.

Mở rộng

  • :is(), :where().
  • Bộ chọn thuộc tính [href^="https"].
  • :focus-within.
