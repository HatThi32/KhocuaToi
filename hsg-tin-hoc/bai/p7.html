Đệ quy là gì?

Khái niệm

  • Đệ quy: hàm gọi lại chính nó với bài toán nhỏ hơn.
  • Cần hai phần: trường hợp cơ sở (dừng) và bước đệ quy (gọi tiếp).
  • Thiếu cơ sở → gọi mãi → RecursionError.
Công thức: n! = n × (n-1)! và 0! = 1. “0! = 1” là cơ sở; “n × (n-1)!” là bước đệ quy.

Ví dụ đời thường: hai tấm gương đối diện; búp bê Nga lồng nhau.

    if n == 0:

Fibonacci đệ quy

def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print([fib(i) for i in range(10)])
F(0) = 0, F(1) = 1, F(n) = F(n-1) + F(n-2). Hai lời gọi đệ quy → cây gọi phân nhánh.

from functools import lru_cache
dem = 0
def fib(n):
    global dem
    dem += 1
    return n if n < 2 else fib(n - 1) + fib(n - 2)

@lru_cache(None)
def fibm(n):
    return n if n < 2 else fibm(n - 1) + fibm(n - 2)

print(fibm(90))

def ucln(a, b):
    if b == 0:
        return a
    return ucln(b, a % b)

Đệ quy trên danh sách: tổng và max

def tong(a):
    if not a:
        return 0
    return a[0] + tong(a[1:])

def lon_nhat(a):
    if len(a) == 1:
        return a[0]
    m = lon_nhat(a[1:])
    return a[0] if a[0] > m else m

print(tong([3, 1, 4, 1, 5]), lon_nhat([3, 1, 4, 1, 5]))
Cắt lát a[1:] tạo danh sách mới nên mỗi lần tốn O(n); dùng chỉ số để đỡ sao chép nếu cần tối ưu.

Tháp Hà Nội: ý tưởng

Luật chơi

  • 3 cọc A, B, C; n đĩa xếp từ lớn đến bé trên A.
  • Chuyển hết sang C, mỗi lần một đĩa.
  • Không đặt đĩa lớn lên đĩa bé.
Chia nhỏ: (1) chuyển n-1 đĩa từ A sang B (qua C); (2) chuyển đĩa lớn nhất A→C; (3) chuyển n-1 đĩa từ B sang C (qua A).

Số lần chuyển: T(n) = 2·T(n-1) + 1 = 2ⁿ - 1.

Tháp Hà Nội: cài đặt

def hanoi(n, a, b, c):
    if n == 0:
        return
    hanoi(n - 1, a, c, b)
    print(a, "->", c)
    hanoi(n - 1, b, a, c)

hanoi(3, "A", "B", "C")
hanoi(n, nguồn, trung gian, đích). Với n = 3 có 7 bước; n = 10 có 1023; n = 64 là 1,8·10¹⁹.

Luỹ thừa nhanh

def mu(a, n):
    if n == 0:
        return 1
    t = mu(a, n // 2)
    return t * t if n % 2 == 0 else t * t * a

print(mu(2, 10), mu(3, 13))
print(mu(2, 100) == 2 ** 100)
a^n = (a^(n/2))² (n chẵn) hoặc (a^(n/2))²·a (n lẻ): chỉ O(log n) phép nhân thay vì O(n).

Sắp xếp trộn (merge sort)

def tron(x, y):
    r, i, j = [], 0, 0
    while i < len(x) and j < len(y):
        if x[i] <= y[j]:
            r.append(x[i]); i += 1
        else:
            r.append(y[j]); j += 1
    return r + x[i:] + y[j:]

def sap(a):
    if len(a) <= 1:
        return a
    m = len(a) // 2
    return tron(sap(a[:m]), sap(a[m:]))

print(sap([38, 27, 43, 3, 9, 82, 10]))
Chia đôi → sắp từng nửa → trộn hai dãy đã sắp. Độ phức tạp O(n log n) mọi trường hợp.

Tìm max bằng chia để trị

def lon(a, l, r):
    if l == r:
        return a[l]
    m = (l + r) // 2
    return max(lon(a, l, m), lon(a, m + 1, r))

a = [3, 17, 4, 9, 11, 2]
print(lon(a, 0, len(a) - 1))
Chia dãy thành hai nửa, lấy max của hai max. Cơ sở: đoạn có một phần tử (l == r).

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • Đệ quy = cơ sở (dừng) + bước đệ quy (bài toán nhỏ hơn).
  • Thiếu cơ sở hoặc không thu nhỏ → RecursionError (giới hạn ≈ 1000).
  • Fibonacci đệ quy O(2ⁿ); ghi nhớ hoặc vòng lặp → O(n).
  • Chia để trị: chia – trị – kết hợp; ví dụ merge sort O(n log n), luỹ thừa nhanh O(log n).
  • Tháp Hà Nội: 2ⁿ - 1 lần chuyển.

NÂNG CAO

Điều dễ nhầm và mở rộng

Bẫy thường gặp

  • Mỗi lời gọi tốn bộ nhớ ngăn xếp: độ sâu n → O(n) bộ nhớ.
  • fib(n) ngây thơ gọi lại cùng giá trị nhiều lần.
  • Mọi hàm đệ quy đều có thể khử bằng vòng lặp + ngăn xếp.
  • sys.setrecursionlimit() tăng giới hạn nhưng có thể gây lỗi bộ nhớ.

Mở rộng

  • Quay lui (backtracking): thử – sai – lùi (N quân hậu, hoán vị).
  • Quy hoạch động = đệ quy + ghi nhớ.
  • Quick sort: chia theo điểm chốt.
