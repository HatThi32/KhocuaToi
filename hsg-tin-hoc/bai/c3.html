Mục tiêu và nội dung bài

Sau bài học, em có thể

  • Viết truy vấn SELECT … FROM … WHERE.
  • Dùng ORDER BY, LIMIT, DISTINCT, LIKE, IN, BETWEEN, IS NULL.
  • Dùng hàm tổng hợp COUNT, SUM, AVG, MIN, MAX.
  • Dùng GROUP BY và HAVING; phân biệt WHERE và HAVING.
  • Nắm thứ tự thực hiện câu truy vấn.

  • SELECT cơ bản

Hàm tổng hợp trên toàn bảng

SELECT COUNT(*) AS so_hs,
       ROUND(AVG(diemtb),2) AS tb,
       MAX(diemtb) AS cao_nhat,
       MIN(diemtb) AS thap_nhat,
       SUM(diemtb) AS tong
FROM hocsinh
Hàm tổng hợp gộp nhiều dòng thành một giá trị. COUNT(*) đếm dòng; AVG, SUM, MAX, MIN bỏ qua NULL.

HAVING: lọc nhóm

SELECT lop, COUNT(*) AS so_hs,
       ROUND(AVG(diemtb),2) AS tb
FROM hocsinh
GROUP BY lop
HAVING COUNT(*) >= 2

Thứ tự thực hiện câu truy vấn

Viết khác với chạy

  • 1. FROM: lấy bảng.
  • 2. WHERE: lọc dòng.
  • 3. GROUP BY: nhóm.
  • 4. HAVING: lọc nhóm.
  • 5. SELECT: chọn cột, tính biểu thức.
  • 6. ORDER BY: sắp xếp.
  • 7. LIMIT: cắt số dòng.
Vì WHERE chạy trước SELECT nên không dùng được bí danh định nghĩa trong SELECT; còn ORDER BY (chạy sau) thì dùng được.
Thứ tự viết: SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT.

TRỌNG TÂM

Những điều phải nhớ

Ghi nhớ

  • Thứ tự viết: SELECT – FROM – WHERE – GROUP BY – HAVING – ORDER BY – LIMIT.
  • WHERE lọc dòng; HAVING lọc nhóm (có hàm tổng hợp).
  • COUNT, SUM, AVG, MIN, MAX; AVG, SUM bỏ NULL; COUNT(*) đếm cả NULL.
  • Cột trong SELECT không nằm trong hàm tổng hợp phải có trong GROUP BY.
  • LIKE: % nhiều kí tự, _ một kí tự; BETWEEN gồm hai đầu.
Cần…Dùng
Lọc dòngWHERE
Lọc nhómHAVING
Giảm dầnORDER BY … DESC
Loại trùngDISTINCT
Dùng hàm tổng hợp trong WHERE là sai; dùng HAVING.
NÂNG CAO

Điều dễ nhầm và mở rộng

Bẫy thường gặp

  • COUNT(cột) khác COUNT(*) khi có NULL.
  • = NULL luôn không đúng; dùng IS NULL.
  • Chuỗi so sánh LIKE không phân biệt hoa/thường tuỳ hệ.
  • ORDER BY nên đi kèm LIMIT khi lấy “top n”.

Mở rộng

  • CASE WHEN … THEN … END: rẽ nhánh trong SQL.
  • Hàm cửa sổ (RANK, ROW_NUMBER).
  • UNION, INTERSECT, EXCEPT.
